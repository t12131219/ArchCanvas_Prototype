# 通用语义状态的自动局部路径选择

本页保留该阶段的历史测量。2026-10-21 完整默认自适应对照已完成，当前 22 张 SVG、真实 UI 往返及限制见[独立完整比较](adaptive-comparison.md)。旧阶段的 549 项测试及两条局部路径没有改标为当前结果。

目标仍是可逆的中间语义状态：主图组织接近人工认证和设计的架构图，其下保留角色、计算路径和最细证据；同一套规则还要服务陌生、残缺、混合以及状态和控制结构。当前阶段没有完成整体目标。

## 本阶段的改变

结构优先的局部自适应规划此前主要比较整组嵌套角色展开。现在增加单条已认证角色路径的候选，并在现有测量预算中比较同一拥有者的整组与局部替代。候选来自实际附属证书的本地角色引用，保存完整的键数组；不按模型名称、案例 ID、源码哈希或特定角色名称选择。

已经部分选中的区域仍可以提供其他路径或整组细节。每个规划过程仍最多36次预投影、3个真实布局测量；优先保留已有关系机会，避免大量路径候选排挤整组方案。最终选择核对实际显示、操作数接线、条件和未知边界以及面积、交叉和路由质量。这是有限启发式，尚不是全图摘要与细节的联合最优规划。

选中端点自己的输入绑定必须出现在成功路由的实际边中；不能仅凭它已显示、周围其他计算有收益，或旧回执声称完成而通过。回归检查移除选中路径的实际输入路由，即使保留旧的“已接线”回执，规划仍须拒绝该方案；已经验证的路径也不能随后丢失接线。

检查器会把自动选中的路径显示为可收起状态。手动操作固定当前选择并关闭自动规划；收起一条时，其他自动选中路径会转为保留的手动请求。

当前549项测试通过；20张正式SVG和2张语义UI SVG通过独立路径、终端、绑定、来源外框和输入布局审核。26个浏览器原生面板测量1269处节点文字和11处边标签，未发现越界。新增的[精确角色身份与上下文标题](role-identity.md)保留角色键数组，区分带点键和嵌套键，并使数字成员标题保留其所在字段；选择策略和预算未改变。

真实编辑器序列为 `28 → 保存重开28 → 手动保留一条25 → 收回13 → 最细源码144 → 重开语义状态28`。实际源码状态包含全部144节点、145条边；返回后的SVG与原自动状态、按保存请求重建的CLI SVG逐字节一致。Transformer原始源码投影另核对3371节点、3663条边全部恢复，IR不变。

本阶段后续还纳入了[通用路由重复计算优化](route-memoization.md)：每条路由内部复用候选分数、网格线段检查和已有线段范围。新完整测试和上述实际SVG、UI及原生文字审核均已重新执行，保持原有语义状态和实际输出。独立浏览器固定前沿测量不能代替下述完整自动规划对照。

## 限制和未完成审核

更多细节增加了高度，全图适配后的文字更小；MixedBoundary交叉增加，长上下文路径仍明显。数字角色标题已保留所在字段，但通过文字包含和绑定检查仍不等于整体视觉质量已经理想。

本阶段当时尚未完成的大型默认对照，现已在独立目录验收。原进程 51885 保存冻结基线后以 143 退出，续跑当前版本的 5446 已以 0 退出。当前主图 80 图元、91 边，三次额外候选均未采用，完整计算耗时 421.722 秒；详见新记录。候选次数上限不限制同步路由的实际耗时，渲染性能仍是问题。

当前144节点的实际UI审核，以及3371节点的源码投影审核，也不证明数千节点SVG的路由、可读性或浏览器交互性能。专用参考的全面接近、主图与局部细节协同，以及更广的未见状态/路由/影响组合仍未完成。
