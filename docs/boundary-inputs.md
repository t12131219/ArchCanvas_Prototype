# 条件与未知边界的输入布局

原有外部输入端点可以按真实消费位置靠近接收区域，仍留在区域之外。可见条件或未知边界允许接收连线；不能穿越其受保护内部或祖先，也不能移动受条件保护、可变、具有身份或仅运行观测的输入。没有复制节点、改变归属或替换操作数。布局凭据新增 `conditional_uses`，独立审核逐项核对条件及真实 SVG 路径。

自动几何门槛保持：线长至少减少 10%，宽度和面积最多增加 12%，高度、交叉、接触和失败路由不得增加。规则由局部依赖触发，无模型名称、案例 ID、源码哈希或专用坐标分支。

## 实际结果

固定一张主图、两张详图及原始作用域，生产图组规划器在一次原位细化试验中将直接表达目标从 66 提升至 74，原有 66 个目标保留。被细化详图从 30 节点、3 交叉、1404×1268 变为 43 节点、4 交叉、1404×2784。同一展开候选在本次输入布局改动前有 19 个交叉、线长 26511.5；当前为 4 个交叉、线长 17675，尺寸相同。条件 false 分支用途仍独立保留。

相对冻结历史图组的 49 个直接目标，当前仍缺少 8 个历史目标、新增 33 个。这是三张图预算内的一次继续展开，并非重新完成全部紧凑规划或证明专用图全面收敛。

陌生源码夹具覆盖条件、未知、可变与交织结构，抽取仅使用静态源码。自动候选因宽度、面积、高度或接触代价不合格时保留原布局。UnknownWorkshop 的显式对照从 2 个交叉降为 0，但宽度 908→1034，增加 13.8%，因此自动方案正确拒绝它；不能把显式对照称为自动选中。UnknownBraided 两张图仍有端口标签附注问题，独立报告保留这项未解决质量问题。

```bash
python3 tools/extract_boundary_inputs.py

node tools/audit_boundary_inputs.cjs
node tools/audit_boundary_inputs.cjs --large
python3 tools/check_boundary_inputs.py
python3 tools/build_boundary_inputs_review.py
```

产物位于 `verification/boundary-inputs/current/`。独立审核核对 17 张实际 SVG、精确覆盖、边界、条件凭据和几何；源布局 JSON 可复现并忽略提交。完整测试 56 组、684 项通过。浏览器原生 SVG 文字测量覆盖 17 张图，未发现文字边界失败；Transformer 继续展开对照和通用案例均保存浏览器截图。

本次为静态 SVG 和浏览器文字审核，尚未验证 Transformer 编辑器导出、保存重开等交互。原始投影的 3371 节点、3663 边恢复在此前已验证，数千节点整体 SVG 路由与浏览器性能仍待单独验收。专用参考的完整逻辑和视觉接近目标仍未完成。
