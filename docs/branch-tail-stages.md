# 可逆分支末端与语义阶段组合

通用画布的角色关系状态可以把一个已证明的较长分支的末端单输入操作，纳入已有的加法与后归一化摘要。标题仍是 Add & Norm，说明同时列出实际末端操作，例如 tanh 或 Dropout。这是展示边界的组合，不是把该操作解释为透明、纯函数或恒等变换。原始 IR、调用、资源、操作数和结果槽继续保留。

选择只依赖局部证书和真实边：末端必须只有一个数据输入，结果只能沿独占、无条件、同作用域的整值别名路径到达已证明的分支操作数。整个分支只有一个操作时，仍单独展示该操作。多输入、结果逃逸、条件、可变操作、对象身份、运行证据或不兼容效果阻止该组合。模型名、源码类名、案例 ID 和参考版式不参与生产选择。

源码作用域和展示外框分别检查。末端、加法及归一化必须属于同一原始源码父区域。它们可以跨过已经展开、没有独立语义或控制边界的源码数量分段；不能借此打开原本折叠的区域，也不能跨过源码函数、认证模块、条件或循环边界。重组后重新计算分段成员、切边及检查面板的发现成员。未认证的 CNN motif 也不会在本规则中自动拆开，因此 ImageWeave 保留原图。

在不可变的 f251215 基线上，八个实际陌生输入覆盖独占末端、结果复用、未知调用、条件、图像计算、可变操作、多输入及整个单操作分支。UnaryWeave 的 7 图元 / 5 边缩为 6 / 4，高度从 644 降至 562；继续展开恢复 9 图元 / 6 边。InterruptedWeave 和 ConditionalWeave 只组合独立成立的已知区域，未知和条件部分仍可见。五个保护案例的 SVG 与基线逐字节一致。

同一源码的 Transformer 默认语义状态从 94 / 102 变为 89 / 97，尺寸从 2588 × 4364 变为 2588 × 4118，交叉仍为 57，无关接触仍为零，没有新增几何限制。五处末端被纳入摘要且明确打印。这是更紧凑的局部语义组织；内部角色、跨区域连接和整体阶段版式仍与专用参考有明显差距。专用全展开对应通用图的目标中间状态，更细展开不是被删掉的替代品。

阶段验证使用完整测试、20 份实际 SVG 的独立 XML、路径、成员、切边及角色审核，以及真实浏览器的原生文字测量和编辑器展开、保存、重开、折回。原始源码投影仍可恢复 3371 个节点 / 3663 条边；这不证明数千节点同时 SVG 路由或交互性能。更深的整图角色状态、本轮未见组合验收及全局图组规划仍需后续验证，不把默认图的局部改善推广为完整目标达成。

## “从细节折叠”与“继续展开”的含义

概念上，详细事实位于底层，语义摘要在其上组织出可逆的展示状态。实现不要求先把数千节点全部绘制出来再逐个收起，而是直接从不可变 IR 编译当前可见部分。语义关系可以重叠，画面容器有自己的归属；因此这也不是只按源码父子树缩小节点数量。

目标阅读顺序可理解为：整图概览 ↔ 语义架构状态 ↔ 局部角色和操作细节 ↔ 原始源码事实。专用案例的完全展开作为语义架构状态的评价参考，不定义通用层的展开终点。不同区域可以采用不同粒度；一个区域细化时，其他区域可以继续保持摘要。证据模式（源码、运行、合并）是另一维度，不能当作细节等级。

当前 3371 节点、3663 边的验证证明原始源码投影可完整恢复，并未证明角色视图中连续点击“展开全部”就会进入同一原始投影，也未证明数千节点同时路由和浏览器交互的性能。局部可逆展开、保存重开与原始投影完整性分别验证。尚未抽取到的 Python 行为，也不会因为展开操作自动变成已知事实。

后续靠拢专用图需要继续完善通用语义边界、端口映射及关系布局；减少节点数量或达到某个数字本身不构成验收。生产规则根据局部计算证据选择摘要和布局，不以 Transformer 名称或参考图坐标选择行为。
