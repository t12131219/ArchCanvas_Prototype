# Measured cross-scope entry ports

Expanded module title bands remain pass-through. Concrete nodes and unrelated
module bodies remain obstacles. This follows the explicit title-routing request;
it does not change canonical facts or semantic folding.

## General rule

When a source lies wholly to the left or right of a visible expanded receiving
frame, propose that source's facing side and the reciprocal receiving side.
The rule reads geometry, containment and real dependency edges. It never reads
model names, source hashes, case IDs, Q/K/V labels or operator families.

Eligible dependencies are unguarded data, aliases and interface bindings.
Ancestor endpoints, sources inside the receiving frame, condition/iteration
metadata, SCC feedback, state/design routes and existing context channels are
excluded. Every member of a bundled edge must also be eligible.

The renderer groups proposals by the same visible source and receiving frame,
orders groups by current crossing involvement, and measures at most three.
A trial reroutes a copy of drawing state, then applies the normal selected-route
polish unless explicitly disabled. It is accepted only when it strictly reduces
crossings relative to the latest accepted result, retains canonical facts and
fixed node geometry, and introduces no additional contacts, ambiguous overlap,
route/label failures or quality issues. Dimensions and font legibility cannot
regress, and total wire length is capped at 102% of the original result.
Applied constraints, realized drawing relations and fulfilled expression goals
must survive every accepted step, including gains from earlier steps.

Physical port sides and coordinates deliberately may change. Sibling uses of a
moved source can receive new port offsets. Canonical source/target identities,
operand slots, conditions, references, accounting and the selected frontier are
preserved; this change makes no new input-role or execution-order assertion.

`paperCrossScopePorts:false`, manual offsets, print output, or more than 128
visible edges bypass this automatic search. The layout exports accepted
`cross_scope_ports`; routing diagnostics retain every measured trial, including
rejections. Rejected trial caches and paths do not replace the selected paths.

## Reproduction and review

The reference implementation is frozen at `5dbf190`. Run from the repository:

```sh
python3 tools/freeze_cross_scope_ports.py
node tools/audit_cross_scope_ports.cjs
node tools/audit_cross_scope_ports.cjs --large
python3 tools/check_cross_scope_ports.py
python3 tools/build_cross_scope_ports_review.py
node tools/audit_source_expandability.cjs verification/helper-contracts/current/Transformer-current.json verification/cross-scope-ports/current/source-expandability.json
python3 tools/run_local_tests.py
```

Artifacts are under `verification/cross-scope-ports/current/`. Large routed JSON
is ignored and regenerated by the producer. Baseline SVG hashes must reproduce
the prior selected graph set. The checker independently parses actual SVG
paths, dimensions, crossings, wire length, concrete-node clearance, expression
assignments, port sides, canonical operands, accounting and unchanged positions.

The seven source-derived audit inputs cover same-source uses, mixed and broken
computations, interleaved inputs, conditional, unknown and state boundaries.
Four additional fixtures are explicitly **synthetic IR**, not source extraction
claims: unfamiliar reconvergence, a rejected wire-budget tradeoff, an opaque
boundary and guarded uses. Native SVG text is separately checked in the browser.

## Measured results and limits

The main selected Transformer panel changes from 35 to 29 crossings at identical
73 nodes / 82 edges and 1968 × 3594. Wire length increases from 46513.6 to 46917
(0.87%). The two selected detail panels retain 3 and 16 crossings respectively.
All 74 previously directly expressed graph-set goals survive; both extra graph
trials are rejected for crossing cost. This does **not** recover the earlier
27-crossing main result from `723ab94`.

The synthetic unfamiliar reconvergence changes from 5 to 4 crossings and wire
length 5964.5 to 5491.2, with the same 22 nodes / 20 edges and 956 × 1084. The
wire-budget tradeoff, opaque variant and conditional variant remain byte-identical
to their baselines. The seven source-derived small cases also remain unchanged.

All 30 exported SVGs pass independent checking and native browser text bounds.
The full suite passes 61 groups / 720 tests. Browser screenshots show remaining
long outside routes in the unfamiliar graph, and substantial differences from
the dedicated reference in reading direction, semantic grouping and source-detail
density. This is a local routing improvement, not complete reference convergence.
Deterministic re-rendering is tested; interactive editor save/reopen was not
repeated for this round.
