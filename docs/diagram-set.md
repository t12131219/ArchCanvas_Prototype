# 通用语义主图与局部详图

目标仍是在通用图中形成接近专用架构图的中间语义状态，并保留更细展开。图组为主图省略的角色与计算提供局部阅读入口；它不替代主图的语义及视觉收敛，也不把所有细节塞进同一个超长画面。

`semantic_studio/diagram-set.js` 由编辑器和 `tools/export_diagram_set.cjs` 共用。规划器读取当前焦点、证据范围、实际可见边界及尚未表达的目标，提出独立模块或局部关系详图。认证区域可显示已有角色；陌生但可解析的区域按实际计算路径展开。未知、状态、条件、循环、可变操作与对象身份边界不授权自动展开内部。它们已有的接口关系可以单独检查。

规则不读取模型名、类名、案例 ID、源码哈希或参考坐标来决定行为。每个原始实例仍有独立目标；相同结构的代表不能代替其他实例完成直接路径目标。

CLI 有界地顺序试画候选图，只有实际质量合格、并新增直接表达目标的详图才加入图组。预算或质量限制导致的缺口明确保留为 `deferred`；规划意图和一个摘要外框均不算细节已表达。覆盖要求实际核心节点与路径可见，核对生产者、结果槽、别名路径、最终消费操作数、边类型、条件和证据，普通计算还要有全部输入路径。主图及原始 IR 均保留。

编辑器在画布的“角色关系”状态提供候选详图按钮。用户可打开局部图、继续手动查看，或返回原主图。候选入口本身不表示该图已经通过质量审核，也不表示其全部内部目标已经完成。保存图文档包含局部状态与主图返回状态；CLI 导出 SVG、可继续查看的图文档、导航页和覆盖清单。

## 本阶段结果

六组输入共 21 张实际 SVG；所有主图与冻结基线逐字节相同。

| 输入 | 图面数 | 主图直接表达 | 图组直接表达 | 待展开 |
|---|---:|---:|---:|---:|
| FiberBlend | 3 | 18 / 25 | 22 / 25 | 3 |
| BrokenFiberBlend | 3 | 16 / 23 | 20 / 23 | 3 |
| SameSource | 5 | 7 / 34 | 25 / 34 | 9 |
| MixedWeave | 5 | 8 / 43 | 23 / 43 | 20 |
| UnknownFusion | 1 | 12 / 12 | 12 / 12 | 0 |
| Transformer | 4 | 36 / 1855 | 60 / 1855 | 1795 |

这里的目标是当前源码焦点内逐实例的直接细节表达，不是架构语义覆盖率。Transformer 主图仍为 89 图元、97 边，2588 × 4118 px，57 交叉、0 无关接触；三个局部角色详图各 21 图元、27 边。主图布局和专用参考接近度没有因本阶段改善。

新的 FiberBlend 组合了框架 RNN 状态接口、门控片段、共享结果、TopK 多结果、条件和未知调用；BrokenFiberBlend 将其中一个权重来源改为未知。两者仅静态抽取，不执行模型。测试还覆盖错误端口、结果槽、别名终端条件及证据、失败路径、质量不合格、改名、证据范围和文档重建。

## 验证与范围

474 项完整测试、21 张实际 SVG 的独立路径与回执审核、独立 Python 图组分配复核、587 处浏览器原生比例节点文字测量和编辑器保存重开分别记录。文字最小字号为 13 px，未发现越出形状边界。编辑器序列为主图 20 → 局部 7 → 重开 7 → 返回主图 20；返回 SVG 与原主图逐字节相同，局部 SVG 与 CLI 相同。最终代码刷新后另行重开并返回复核。最新结论见 `verification/diagram-set/current/validation-report.json`。

图面和试画次数有上限，但没有硬性墙钟时间保证；全图目标发现与同步 UI 渲染仍可能昂贵。当前规划也不是主图折叠、局部表达和详图分配的全局联合优化器。更广泛的保留未见组合、完整状态/控制路由组合、主图与专用参考的逐关系对应，以及数千节点同时路由和交互仍需继续验证。原始源码投影完整性单独记录，不用于证明大图交互性能。
