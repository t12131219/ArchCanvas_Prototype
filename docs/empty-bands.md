# 全局空白横带压缩

同一语义状态中的局部展开、来源外框和端口安排，会留下仅被竖线穿过的空白横带。本轮在最终跨区入口复核之后，复用已有空白带几何原语，对整张 canvas 做一次共同的单调纵向映射；不重新布线，不增加语义解释或改变折叠前沿。规则不检查模型名、类名、案例 ID、源码哈希或参考坐标。

## 保护范围与接纳条件

只考虑画面上下各保留 24px 之外的区域。具体节点、展开模块的完整标题、框底边、水平路径、端口标签及每条路径的两个终端均保留 8px 排除区；已经实现的入口带间距和分层标签通道也排除。只删除剩余长度至少 16px 的连续空白。

所有节点和路径共用同一个映射。具体节点的宽、高、字号、文字和形状不变；容器只缩短空白主体。端口标签直接映射原来的标签盒，不重新选择标签位置。操作数行、源码声明列序及固定调用输入的当前几何记录同步更新；之前的试排诊断仍描述之前的阶段，审核器明确处理两者的坐标关系。

只有面积和高度下降、宽度与线长不增加、交叉数完全保持时才接纳；字号、接触、重叠、标签、路由失败、约束、已有关系及直接表达也不能退化。IR、源码归属、条件、状态、对象身份、操作数与结果槽、逐对象去向和展开状态均保持不变。这种几何变换不依赖区域是否具有完整模型名称，亦不把条件或未知计算当作透明路径。

展开模块标题继续允许连线穿过。这里保护标题，是保留文字占用的高度，不是恢复标题路由障碍。

`paperEmptyBandCompaction:false` 关闭新阶段。打印、手工偏移、显式指定标签间距、历史标题避让模式、超过 512 个可见节点或 2048 条可见边、有路由失败或未放置标签时不压缩。手工请求和资源限制保持明确，不以折叠更多内容代替它们。记录位于 `diagnostics.routing.empty_band_compaction`，每张图最多测量一个候选。

## 正式结果

冻结基线为 `b37c74e`，相同输入与状态直接比较。

| 第一张详图 | 44 / 48，不变 | 2784 → 2466 | 17126.3 → 15340.3 | 3，不变 |

三张 Transformer 图的宽度仍为 1968、1404、1710px。主图删除一个 69.5px 空白带，第一张详图删除四个空白带、合计 318px。早期试验曾删除 346px，正式实现额外保留 28px 的既有分层标签通道。第二张详图没有合格空白带，未作改变。

陌生条件、未知终端、共享身份三个合成输入有压缩收益；状态终端输入维持原样。它们明确标注为合成 IR，只证明绘图变换与事实保留，不证明 Python 抽取能力。另有 11 个已有陌生、条件、未知、交织和混合源码/拓扑案例，本轮均保持原样，不能将其描述为新增视觉收益。

本轮也复试了在最终入口优化之后按源码声明顺序调整主图第三组分支，交叉仍从 15 增至 18，线长增加，因此没有纳入生产规则。当前第三组仍为 key、value、query；跨不同来源的角色组织、阅读方向和整图表达密度仍未解决。

## 验证与已知限制

完整本地测试为 69 组、796 项通过，含新增 7 项。覆盖实际共同映射、原始绑定、具体尺寸、标题/框底/横线/标签/终端排除区、分层间距、配置与资源边界、未知/状态/控制/共享身份、改名以及保存和折叠恢复。两个既有历史 SVG 比较显式关闭新增压缩阶段，继续检验它们原来的阶段行为。

独立 Python 审核读取 37 张实际 SVG，重新测量路径、节点、条件与标签，检查共同映射、canonical 绑定、终端、已有源码声明证据、约束与逐对象去向。三张 Transformer 图合计保留全部 74 项直接表达目标。五种人为损坏（具体节点高度、标签位置、物理终端、消费槽、跨标题删除）均被拒绝；最后一种同步伪造节点、标签和路径坐标，仍因实际标题占用而失败。

`ForeignOpaque-before/current` 各有 4 处既有非相关线段接触；两张 SVG 未变化，审核报告明确列出。本轮没有声称所有输入均零缺陷。

浏览器原生测量 37 张 SVG 的 1628 段节点文字与 64 个端口标签，无越界。实际编辑器完成陌生条件样例 3 → 3（重开）→ 1（折叠）→ 3（恢复）的往返；四次导出、主图导出及第一张详图导出共六张 SVG 均与正式产物逐字节一致。目视检查包含完整陌生样例、详图上下部分和专用参考对照，截图保存在审核目录。

源码投影再次恢复全部 3371 个节点、3663 条边和 canonical ID，原始 IR 未变。这仍不证明数千节点整图路由或浏览器交互性能，也不证明任意语义预设一次“展开全部”即可呈现全部事实。本轮未新增联合图组规划；整体语义与版式收敛目标保持未完成。
