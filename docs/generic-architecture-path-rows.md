# 通用短串行计算路径的行布局

本轮把“在宽模块里利用横向空间、压缩过长的纵向计算链”提炼为通用布局规则。选择依据只有当前可见依赖、源码归属、证据边界和实测几何，不读取模型名称、案例 ID、源码 SHA 或专用图坐标。Transformer 是双状态视觉参照；普通卷积与线性模块同时验证同一条规则。

这次改变的是同一语义切面的几何，不折叠、删除或认证新的计算。概览、语义详图和更细展开仍使用同一份原始 IR。规则面向通用结构适用：分支、条件、状态、共享、循环和未知语义继续使用各自已建立的组织方式，不强行排成串行链。

## 适用条件与选择

在严格有序的展开源码模块或认证模块列中，检查一个模块内的 2–6 个可见计算子节点。只有内部边恰好形成逐项连接的单一有向路径、原布局逐项纵向排列、没有条件/反馈/状态/运行证据或身份边界时，才尝试行布局。父模块本身有受保护证据也不参与。普通源码模块已经被推断为卷积等语义类型时，仍按源码模块身份参与，判断只用 `source_class` 是否存在。

简单计算卡片保持字号、标题和说明，按文字的自然宽度缩窄到不小于 154 px；符号、结构化读取、调用边界和管道证据卡片保留原尺寸。在既有框宽内测量行容量，保留依赖顺序，以箭头连接交替方向的各行；上行和下行主流程均可使用。保留每一个运算、所有父子归属、每一条精确绑定与调用。布局记录包含顺序、行容量、卡片尺寸前后值、框高前后值和物理起始方向。

最终比较纵向原方案、左起方案、右起方案，最多两个行布局候选。采用候选必须同时满足：

- 面积严格减小，宽度和高度均不增加，字号不减小。
- 交叉、不相关接触、不相关路径重叠、路由失败和未放置标签均不增加。
- 原始绑定、节点/边完整归属、已满足的直接和摘要目标、已实现的关系与约束保留。
- 逐边总线长最多增加 2%。这是明确记录的面积与线长取舍，不声称所有指标均改善。

不满足时保留原纵向方案。手工位移、显式退出和超过 128 条可见边的图不做自动候选选择。未改变已有的模块标题可穿越策略。

## 验证与展开

95 组、1074 项全量测试通过，架构编排含 35 项。定向验证包括上下主流程、左右起始方向、普通卷积与线性路径、分支、条件、可变状态、共享身份、运行证据、反馈、额外反向边、手工位移、资源上限、显式退出、模型/家族/来源重命名、保存重开。

正式套件覆盖 43 份输入、102 个状态。独立检查原始 IR、架构事实、精确绑定、完整节点和边归属分区、表达目标保留、实际 SVG 路径、交叉/接触/重叠与实体障碍，并从实际边重算线长。对每条行布局独立确认它确为直接串行依赖、顺序未变、行宽与原框一致、字体未缩小、子节点仍在所属框内；也独立检查纵向备选的实际 SVG。102 张 SVG 的 1392 个可见图元通过浏览器原生文字边界检查。左右两种试验并非都通过：Transformer 详图的左起备选有 19 处交叉而被拒绝，右起备选保留 14 处交叉后采用。

实际编辑器完成 Transformer 的 28/37 概览 → 80/80 详图 → 82/81 局部展开 → 保存 → 返回 28/37 → 重开 82/81；普通源码完成 6/4 概览 → 17/13 细节 → 6/4 返回。上述七个实际 SVG 导出均与正式文件逐字节相等。保存的 Transformer 文档保留原始 3371 个节点、3663 条边及概览返回快照。原始 IR 的进一步展开能力保留，尚未验证数千个节点同时显示的巨型 SVG 性能。

## 复现

将 `67039ef` 的 `semantic_studio` 用 Git archive 解包至 `/tmp/archcanvas-path-rows-67039ef`。使用 `semantic_adapter.analyze` 从 `tests/semantic_fixtures/path_rows.py` 静态提取 `SpatialPipeline` 和 `BranchedPipeline`，不执行模型。运行：

```
node tools/capture_path_rows.cjs
python3 tools/build_path_rows_review.py
python3 tools/check_path_rows.py --geometry-only
python3 tools/run_local_tests.py
```

完整 `python3 tools/check_path_rows.py` 还要求实际浏览器文字测量和编辑器导出文件。原生测量表达式保存于 `verification/path-rows/current/native-measurement.js`；使用 CUA 的只读 DOM evaluate 在 `native-audit.html` 执行。大型布局文档和完整 UI JSON 留在本地，正式 SVG、报告、截图、静态输入与复现工具纳入 Git。测试与捕获期间冻结生产、测试和捕获器文件。
