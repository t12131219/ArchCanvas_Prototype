# 通用原生画布：自由连接点、联合入线与移动校验

日期：2026-10-25。接续已有未提交的迁移工作。本轮不执行 push，原专用 authority、源码事实、F0/F1 和原子展开机制保持兼容。

## 悬浮证据

画布工具条增加“悬浮证据”复选框，每次打开页面默认关闭。启用后，鼠标在节点停留 800ms 才显示；出现前移动鼠标会重新计时，离开节点、开始拖动、缩放、切面变化或关闭开关会取消／隐藏。关闭时不生成提示内容。右侧检查器仍可主动查看完整证据。

## 为什么出现绕行

有两个原因，不能只通过减少路径中的点解决：

1. 通用初始布线优先保留分配过的物理连接点，即使改变两端在矩形边界上的位置能形成直线，也没有主动比较。现在对最多 300 个节点的可见切面，先比较合法的简易自由端口候选，只有实际成本更低才替换。
2. 多输入汇合处采用逐边贪心计算。截图中，残差线先从 add 下方接入，并横穿 dropout 与 add 之间的通道；dropout 的中央直线虽满足几何和端口契约，却会与这条残差线交叉。较高交叉惩罚让它绕到左侧。只优化当前已经交叉的线，也无法发现这个“提前绕开”的局面。

新增 `refineJoins()` 联合比较汇合处的少量入线：为同一结构范围内能够直连的输入选择相对的连接侧，让阻挡它的其他入线从已有通道的侧边进入。同一事务内调整这几条线，验证精确物理端口、终端方向、箭头长度、障碍、所属边界顺序、线段重叠，再比较全图统计。候选必须不增加交叉和折点、线长不超过原状态的 104%，并降低加权成本。

该规则依据实际拓扑、所属范围与几何，不根据 Add、Dropout、Transformer、案例 ID 或标签判断。覆盖向上、向下、向左、向右的数据流与镜像；固定端口、真实障碍、未完成路线、显式总线和超出选中布线范围的连接均不能被擅自改动。复杂情况保留原合法路线，不强行套用直线模板。它用于小切面的初始布线、Apply，以及移动影响范围；数千节点的大图继续采用原有有界路由。

截图对应的三个汇合点均形成“dropout 上侧 → add 下侧；残差 → add 右侧”。实际 DOM 裁切见 `verification/native-interaction/current/join-detail.svg` 和 PNG。

## 为什么所有移动都被拒绝

正式 F1 基线中，多种节点移动均被同一条无关边阻止，原因记录为 `e01535: no legal local corridor`。通用路由允许窄但满足实际描边安全距离的通道（`boundaryLanes:false`），移动流程却无条件要求所有路线再满足更宽的偏好留白。于是移动任意节点都会尝试修复同一条既有窄通道，并在搜索失败时全部回滚。

现在移动与初始布线使用同一条留白规则：偏好通道只在启用该策略时检查；实际描边、障碍、端口、边界和不相干连线重叠仍必须合法。普通节点和含子节点的父模块均已核对成功移动；真实节点重叠反例继续阻止移动。

## 按语义切面认证，按可见几何检查

采用用户提出的分层复用思路，但切面由语义投影决定，不固定为数字层级。

- 载入／导入、创建新切面、源码或连接编辑时，依据完整 IR 和当前投影检查规范节点、精确依赖、操作数、归属、契约与完整 accounting。
- 建立仅存在于内存 WeakMap 中的认证记录。IR、状态、节点语义和边绑定等成为不可变对象；检查切面身份、对象引用和当前拓扑。文件中的 digest 或 `trusted` 字段不能代替认证。
- 纯几何事务复用认证结果，不重复序列化和比较完整源码证据。仍逐次检查当前节点的有限几何与归属、物理端口，并检查可见路线与所有可能被移动遮挡的可见障碍。没有用“只看相邻边”来遗漏无关连线被新位置遮挡的问题。
- 更换 IR、状态、语义对象、receipts、端点、原始边集合、草稿操作或路由契约会失效／重做认证；物理连接点与路线本身一直实时检查。公共 `G.validate()` 仍提供完整校验。
- 撤销快照和实时拖动共享不可变证据，独立复制几何。worker 双向缓存完整证据核心，同一切面后续仅传送可见几何壳；不同切面或证据替换发送新核心。worker 重启后重新建立缓存；缺失的核心明确失败，不能借旧核心完成认证。

完整 IR 一直保存在文档中，没有删除深层证据。保存格式仍为 `archcanvas-native-semantic/1`，renderer 更新为 `native-semantic/10`；1–9 的旧布局和缓存进入迁移来源记录，按当前规则重建。版本 9 是本轮中途状态，其证据保存在 `verification/native-interaction/iteration-1/`。
