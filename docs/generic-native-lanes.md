# 原生通用画布：并行汇入、终端线距与叶节点边缘

日期：2026-10-27。接续 [跨区折返与近距离平行线](generic-native-shortcuts.md)。本轮开始时工作区含上一轮未提交的 renderer 13 改动，均予以保留；本轮修改前代码备份为 `/tmp/archcanvas-lanes-20261027/before-code.tar`。没有提交或推送。

## 截图问题与原因

并行分支此前逐条选择端口，短输入、跨区输入和掩码各自找到合法路线，却没有共同约定汇入面的顺序。只把三条输出改成整齐汇入会与原先从上侧进入投影模块的输入线交叉，因此不能仅替换三个箭头。专用图提供的参考是并行列、几何有序的汇入，以及共享输入在另一侧分叉；生产规则不使用 Transformer、Attention、Q/K/V 名称、案例 ID、源码摘要或专用坐标。

原先的 `separate()` 主要平移内部线段，无法移动与物理连接点绑定的长末端线段；`borderProximity()` 默认只检查展开外框，普通叶节点的边线切触仍可通过合法性检查。因此箭头可以沿 `self.pe` 的上边缘运行，看起来像节点边框的一部分。

## 实现

共享实现位于 `yworks_edge_router_lab/flow-optimizer.js`，由 `generic-semantic.js` 的首次布局，以及 `graph-engine.js` 的移动释放、Apply 调用。

- `convergence()`：识别同一父范围、同排的 2–4 个独立普通分支及共同消费者。按实际输入连接提出同级换序候选，在消费者面向分支的一侧按横坐标分配独立物理槽；分支输入尝试从相反侧接入，其余消费者输入尝试侧边或背面。连同受影响的输入线一起验证，保留可用的原有跨区路径前缀和同值源端口。每次采用前核对完整源事实、所有路线、外框顺序、障碍、操作数槽和全局交叉；交叉、折点、近距离惩罚和实际绘制的贴边惩罚均不得增加，累计线长与同值线段并集最多增加 1%，综合代价必须下降。未得到更好合法结果即回退。
- `borders()`：显式测量展开外框和普通叶节点，保留旧 `borderProximity()` 默认只测外框的接口行为。外框沿用 80px 平行长度、18px 距离；叶节点从 24px 平行长度、12px 距离开始计入。新增的 `separate({borderClearance:true})` 在原近距离分线阶段之后尝试边缘两侧的通道，不把软性美观目标变成新的移动禁止条件。
- `terminals()`：针对仍贴边或接近其他独立线路的长末端，沿同一节点面平移物理连接点和相邻折点。检查槽位间距、箭头末端、完整路线与全局指标；原始 `fixedSource/fixedTarget`、IR、操作数、证据、条件和调用身份不变。每个事务只允许在线长／绘制线段并集最多增加 3% 的范围内减少近线或贴边，且两项都不能恶化，折点和交叉不增加。
- `borderInk()`：按照精确值、源身份和源槽对共线路段取并集，再计算贴边代价。同一个实际绘制的共享线干只计一次；不能把不同值或槽合并。否则把两条真实同值输入整理为共同前缀时，会因为消费者各保存一份路线而重复计算贴边，错误拒绝可读性更好的方案。

这些操作不改变语义切面或删减事实。条件、状态、副作用、未知边界、草稿、手动折点、显式 bus 及不合条件的分支不进入联合换序。Never、曲线、八方向和大于 300 个可见节点或 300 条边的切面跳过新搜索；连接点微调也尊重关闭线距惩罚的设置。大图原有后台分批布线继续使用，没有新增逐帧搜索。

初次布线的新增协作式预算为汇入 700ms、边缘通道 200ms、连接点 200ms，并受整图剩余预算限制；本次正式 F1 三阶段实测约 250/206/207ms。移动释放和 Apply 分别限定受影响边，三个阶段各 70ms，且不重排用户摆放的节点。预算不是硬实时保证。本轮不声称提升数千节点的展开速度。

renderer 为 `native-semantic/14`，schema 不变；1–13 的旧几何保留为迁移来源，当前规则重建。14 文档仍精确恢复保存的位置与端口。有效缓存切面的返回直接保留保存结果，避免 F0/F1 恰好共用一个切面时重复美化覆盖端口；该兼容性由原有往返测试覆盖。
