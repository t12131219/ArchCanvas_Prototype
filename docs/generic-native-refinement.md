# 原生通用画布：无外框标题、语义配色与布线整理

本轮沿用原生主程序，调整自动生成的通用模型展示。没有恢复旧通用 SVG 渲染器，也没有修改源码认证范围。修改前相关文件与完整工作区差异保存在 `/tmp/archcanvas-native-refinement-20261025`；更早的完整迁移前备份仍位于 `/tmp/archcanvas-before-host-migration-20261025-183551/snapshot`。本轮没有 Git push。

## 最外层框改为文字说明

已展开、在当前可见层次中为根、且没有连接直接以它为端点的 composite，显示为居中的模型标题及证据范围／切面说明。实现不检查模型名、案例 ID、源码哈希或专用图坐标。多根结构分别按同一条件处理；折叠的根及承担真实接口的根保留节点形状与连接端点。

原根仍是完整 IR 和可见投影中的逻辑归属节点，其后代、凭据、canonical accounting 与继续展开入口没有删除。展示根没有矩形、展开按钮或大面积鼠标命中区，不产生隐形围墙、进出边界或拖动容器限制；真实标题文字仍作为线路障碍。子模块的源码 parent 不改成 null。其他真实模块的边界、操作数和归属限制继续生效。

标题使用专用图的居中文字形式，不复制 Post-LN、独立参数等未经当前证据证明的注释。较窄模型提供最小标题宽度，内部图居中。小字仍使用节点本身的底色和淡灰字体。

## 自动配色

色板来自 `snapshots/transformer_programmatic_guide/draw_transformer.py`，选色依据是已存在的认证角色、抽取器的 operator 和结构层次，不从节点名称猜测算法。

| 依据 | 色彩 |
| --- | --- |
| 已认证 attention 区域 | `#ffddb3` 橙色 |
| 已认证 feed-forward、卷积／池化操作 | `#c8ebfb` 蓝色 |
| 已认证归一化阶段、normalization | `#fff6bd` 黄色 |
| linear、参数 | `#dfdff8` 紫色 |
| embedding | `#f8d4e1` 粉色 |
| softmax、activation | `#c9f1cd` 绿色 |
| 输入输出、张量形状与搬移操作 | `#cdeaf8` 淡蓝 |
| control、state、buffer、dropout | `#f3f5f7` 中性灰 |
| opaque | `#fff0e8`，保留未知边界样式 |

没有专属认证角色的源码容器，按可见结构区域依次使用淡蓝、淡粉、淡绿、淡紫；内部深度轻微提亮。输入节点不消耗区域色序号。颜色只帮助区分，不证明模块是 encoder 或 decoder；未知操作不获得额外算法认证。改名测试确认选色不依赖标签。

## 布局与布线

原生适配器启用共享纯布局算法中已有的 compound 输入安排：只有真实依赖满足独立入口与后续上下文输入条件时，才尝试并排安排展开区域。控制、条件、状态与未知边界不跨越。候选根据图幅比例和面积条件接受；不是把所有程序排成 Transformer。减少嵌套外边距，不预留整条不可进入的标题带。

对不超过 300 个可见节点及 300 条边、且已经全部合法布线的切面，再进行有限的交叉整理：按交叉数量挑选路径，最多两轮、每轮 32 条，并在路径之间检查约 2.5 秒预算。除现有端口外，尝试其他允许的物理端口及简单正交路线。只有总交叉数下降、整轮总线长不超过原值 104%、且通过原有端口／边界／障碍检查时才提交；其余候选完整回退。预算不承诺单条搜索的最坏耗时。

专用图默认求解路径不启用新的简单端口候选选项。数千节点的通用完整源码切面不进入二次整理，继续使用既有分批布线。待布线状态的线长读数增加“已布线”提示，避免将局部指标理解为全图结果。

## 结果与限制

与上一轮原生主程序的正式捕获比较，同一语义切面保持 F0 30/37、F1 82/80：

| 状态 | 图幅：前 → 后 | 总线长：前 → 后 | 交叉：前 → 后 |
| --- | --- | --- | --- |
| Transformer F0 | 1272 × 2886 → 1226 × 1622 | 32515 → 17331 | 22 → 15 |
| Transformer F1 | 2132 × 6639 → 3047 × 3402 | 78235 → 56995 | 26 → 25 |

F1 高度减少约 48.8%、线长减少约 27.1%，宽度增加约 42.9%；它仍比专用参照更宽。新增整理以一定首次求解时间换取更少的交叉，F0／F1 单独捕获约 2.75／4.75 秒，不能称为首次布线提速。展开测量和路由仍在 worker 中，已保存切面的几何缓存继续复用。

数千原子同时展开时的图幅和完整路线求解仍未解决。本轮没有证明完整 3663 条边全部求解或任意大图拖动都流畅。完整 IR 仍为 3371 节点、3663 条依赖；F1 仍是可逆中间状态。

## 兼容与验证

原生 renderer 更新到 `native-semantic/6`。旧 renderer 1–5 的原生文档保留 IR、状态、authoring 和旧布局来源记录，重新测量当前字形与几何，不直接套用旧外框坐标。当前文档正常往返恢复。没有 nativeLayout 的早期文档也可迁移。

全回归 107 组、1175 项通过，记录在 `verification/native-refinement/current/regression/test-report.json`；这次全回归发生在最后补充普通操作配色及无布局旧文档兼容之前。最终相关测试和冻结源码布线审核单独记录，不能将较早全回归哈希视为最终文件哈希。

生产、测试与捕获器在每次运行期间冻结。自动验证覆盖语义切面等价、完整原始事实、真实 parent、不产生隐形边界、不可伪造标题身份、标题文字空间、普通模型改名配色、旧文档迁移、路线整体改善及回退。浏览器通过 CUA 复核外框消失、顶部注释、颜色层次、普通 MLP 与 Transformer 的 F0/F1 切换；截图及最终结果见同目录验收记录。

最终补验：普通操作配色与无布局旧文档兼容修改后，17 项原生相关测试重新全部通过，43 模型／86 状态的冻结源码布线审核重新达到 86/86；最终摘要及 SHA256 见 `verification/native-refinement/current/acceptance-report.json`，原始日志为 `final-native-tests.txt`，路线报告为 `route-audit.json`。浏览器最终 F1 为 82/80、56995 线长、202 折点／25 交叉，源码与布局校验均为 true，当前 82 个可见单位中的文字边界检查未发现越界。首次进入该状态的浏览器总耗时约 7.6 秒（包含传输、验证及渲染），与单独路由捕获耗时不是同一指标。
