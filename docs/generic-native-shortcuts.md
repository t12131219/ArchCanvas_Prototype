# 原生通用画布：跨区折返与近距离平行线

日期：2026-10-27。接续 [同值分支与并列模块换序](generic-native-fanout.md)。修改前工作区干净；相关源码、测试与捕获器备份在 `/tmp/archcanvas-overlap-20261027/before-code.tar`。本轮没有提交或推送。

## 原因与修复边界

用户截图中的跨区线有两类问题：一条长路线先向右、向上、向右再向下，形成局部折返；另一条独立输入线与它平行约 350px，间距仅 1.6px。两者没有精确共线，因此旧的冲突检查允许这种视觉近似重叠。旧通道优化主要枚举整条路线的 L/Z 形候选，不能在保留长路线中部跨框通道的同时消除局部冗余。

在共享的 `flow-optimizer.js` 增加两阶段几何优化，所有通用模型、导入 IR 使用相同规则；不匹配模型名、角色标签、案例 ID、源码哈希或专用坐标。

- `shortcuts()`：枚举任意两段之间的局部 L 形替代，保留两端物理端口及其余路线。每条边至多两轮；同值分支在一个事务内修改，避免单独简化时暂时拆开共享线干。只有累计线长、折点、交叉、同值线段并集均不增加且完整路径合法，才提交。源码边界穿越顺序、障碍、端口和箭头末端均通过现有约束器检查。
- `separate()`：对不同精确值的平行线段计算近距离惩罚。平行区间至少 40px、距离小于默认 12px 时计入；按严重程度优先处理。尝试将内部线段移到邻线两侧，保持两端坐标；同值共同线段一起移动。保留原有末端净空（原来至少 9px 时仍至少 9px）。近距离惩罚及综合代价必须下降，折点、交叉不增加；每次事务的线长和线段并集允许最多增加 3%。这是视觉区分与距离的权衡，不保证全部指标同时改善。

同值共享线干仍然合法并保留分叉圆点；不同值、不同槽、不同调用不能为隐藏重叠而合并。合绘边保留原成员与完整绑定，仅作为一个现有可见图元整理几何。

两阶段都不移动节点、不删改 IR 或证据、不改变 F0/F1 切面。未完成布线、视觉草稿、手动途经点及显式 bus 不参与。Never 路由策略保持原路径；关闭共线重叠惩罚时不执行近距离避让。曲线、八方向和超过 300 个可见节点或 300 条边的视图不进入本轮搜索。

首次布局在同值分支优化之后执行，协作式预算为局部简化 400ms、分离 300ms，并受剩余整图预算限制。拖动释放和 Apply 各用 100ms，仅修改所选或受影响边。预算并非硬实时承诺；本轮不声称提升了展开速度。源码认证和证据传输继续复用已有缓存。

renderer 更新为 `native-semantic/13`，保存 schema 不变；1–12 的旧布局保留为迁移来源并按当前规则重建，13 继续恢复保存的几何。完整 IR、authoring、切面和原始归属保留。
