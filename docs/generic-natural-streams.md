# 独立输入区域的自然高度与输出侧对齐

本轮继续同时靠拢专用图的概览和语义详图，重点解决两路输入区域中的人为留白与过长跨区连线。生产规则只读取独立入口、可见依赖、源码归属和实测几何；不读取 Transformer 名称、案例 ID、源码哈希或专用图坐标。

原规则为多个独立输入区域补足同样高度，把较短流程的空白放在输入链与末端展开模块之间。本轮增加一个可测量备选：各区域保持自然高度，按输出侧对齐。各自的输入链紧接自身计算，较短区域的外框不再延伸到另一条长流程的输入高度。原始节点、具体调用、输入身份、分支/状态/未知边界和全部绑定保留。位置不表示新的执行顺序。

## 结构适用条件

只有已有独立入口区域对齐策略真正拉伸过、且满足严格有序依赖走廊检查的区域才作为候选：

- 区域通过来自原始外部作用域的接口输入进入，输入只有一条可见使用，没有上游写入。
- 同一父区域存在至少两条这样的入口区域。
- 被收回空白的走廊有可识别的末端展开模块，内部成员严格有向可达，不是平行分支、环或断开的岛。
- 条件、可变、控制、未知、反馈、迭代等边界继续遵守原有禁止拉伸条件，也不会被声称“收回拉伸空白”。

上下两种主流程均在输出侧对齐。相同标题带宽与所有证据说明继续保留。手工位移不参与，显式 `paperArchitectureStreams: 'aligned'` 可保留既有等高布局。自动选择不处理超过 128 条可见边的图。

## 完整候选测量

每个符合条件的图只增加一个自然高度候选。内部短路径的左右行布局先完成自己的有界选择，再比较区域高度；内部候选显式固定区域策略，避免相互递归选择。

候选必须同时保留完全相同的切面、精确绑定、完整节点/边归属、已满足的直接和摘要目标、已应用约束及已实现关系。采用还必须满足：展开框总面积严格减少，逐边总线长不增加，画布宽高不增加，字号不缩小，交叉/不相关接触/不相关重叠、路由和标签问题均不增加。否则保留原布局。

这里的“框面积”是可见展开框面积之和，会包含嵌套框，不能当作画布面积。图幅没有缩小的案例只报告内部留白与线长改善。每条收缩记录包含区域、父区域、自然高度、等高高度及收回空白，选择记录保留前后完整质量指标。

## 验证与证据

95 组、1078 项全量回归测试通过，架构编排包含 39 项。正式套件保留 43 份输入、102 个状态；只有 6 个 SVG 发生变化，包括返回概览的相同状态。定向验证上下两种主流程、自然高度、输出侧对齐、原始绑定与完整归属保留、模块/家族/来源重命名、手工位移、显式退出、保存重开。独立 SVG 审核另对原布局、自然高度候选和最终选择分别检查真实路径、实体障碍、交叉、接触、重叠、输入来源、框高和所有表达目标。102 张最终 SVG 的 1392 个可见图元通过浏览器原生文字边界检查。

实际编辑器完成 Transformer 的 28/37 概览 → 80/80 详图 → 82/81 更细展开 → 保存 → 返回 28/37 → 重开 82/81。保存文档保留原始 3371 个节点、3663 条边及概览返回快照。普通双路 SensorFusion 的 18/11 实际导出，以及普通流水线的 6/4 概览 → 17/13 细节 → 6/4 返回均完成检查。上述 8 个实际 SVG 与正式文件逐字节相等。数千节点同时显示的巨型 SVG 性能仍未验证。

## 复现

将 `1830961` 的 `semantic_studio` 用 Git archive 解包至 `/tmp/archcanvas-spacing-1830961`。运行：

```
node tools/capture_natural_streams.cjs
python3 tools/build_natural_streams_review.py
python3 tools/check_natural_streams.py --geometry-only
python3 tools/run_local_tests.py
```

完整 `python3 tools/check_natural_streams.py` 还需要实际浏览器文字测量和编辑器导出；测量表达式保存于本轮 `native-measurement.js`，在 `native-audit.html` 通过 CUA 只读 DOM evaluate 执行。大型布局文档和 UI JSON 留在本地，SVG、输入引用、报告、截图和复现工具纳入 Git。测试和捕获期间冻结生产、测试与捕获器文件。
