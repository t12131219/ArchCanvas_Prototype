# 通用语义与版式优化的泛化要求

优化对象是通用语义契约、可逆展示层级和绘图规则。Transformer 的专用概览与专用详图用于发现差距；其他程序依据自身可证明的语义获得合适的架构图。两档参照都只是通用图的中间语义切面，下面继续保留具体调用和原始节点。

## 后续每轮的准入要求

1. **先定义结构条件，再实现规则。** 条件应来自已验证契约、真实输入输出、依赖关系、参数共享、控制或状态边界及实际几何。模型名、类名、案例 ID、源码 SHA 和参照坐标不得成为生产选择器。更换程序名称不能改变语义准入；名称长度引起的文字测量变化可以改变几何选择。
2. **覆盖所有受影响的通用语义路径。** 每轮列明哪些证书、节点类型、布局方向和折叠状态可能受影响，并逐项加入审核。新增陌生结构、相同结构的不同算子，以及未知、条件、共享和可变等反例。不同语义可复用相同组织原则；有专门边界约束的语义继续遵守自己的约束。
3. **粗细两档联合验收。** 同时检查概览和语义详图，再验证局部继续展开、具体调用恢复、保存重开和返回。折叠改变可见切面，不删除 canonical IR。原始绑定、操作数位置、调用身份、参数共享与未知事实必须保留。
4. **采用前测量，采用后独立检查。** 保存实际旧 SVG，重新核对新 SVG 的模块顺序、分区、文字、实际线段、端口、障碍、交叉和归属。浏览器再检查原生文字和真实操作。报告实际采用、无适用结构、被拒候选及剩余差距；无收益时保留原布局。

这些要求适用于后续所有通用语义优化。它们不意味着每条几何规则必须作用于每个算子，也不意味着有限套件通过后即可宣称所有陌生模型都已获得理想布局。

## 本轮补上的验证缺口

上一轮正式套件包含 27 份输入、56 个状态，但其中具有 `serial-repeat` 的输入只有 Transformer。较早专项测试中的普通重复程序尚未纳入最近的整图编排审核。本轮从现有普通 PyTorch 测试源码重新静态提取 12 份输入，没有执行模型：

| 结构与边界 | 新增整图案例 |
| --- | --- |
| 准备路径、局部残差和重复 | SignalStack |
| 两路独立重复结构 | TwinStacks |
| 卷积重复、全连接残差重复 | ConvStack、IndependentStack |
| 条件、未知调用、显式状态单元 | ConditionalStack、UnknownStack、StateStack |
| 同一对象反复使用、异构与原地修改 | SharedStack、MixedStack、HeterogeneousStack |
| 中断循环、可变集合 | InterruptedStack、MutatedStack |

新增 34 张实际 SVG 包括粗细两档、可用后续调用的继续展开，以及三个案例的反向流程。不同语义的两档不强制拥有不同节点数。原有 56 张实际 SVG 逐字节复核不变，其中包含 Transformer 概览、详图、进一步展开和返回。总计覆盖 39 份不同输入、90 个状态。独立报告按实际 IR 特征列出覆盖来源，便于后续发现缺口；它没有将案例名称当作生产规则。

## 来自非 Transformer 案例的实际修复

StateStack 的重复处理输出进入 GRUCell。架构概览中，`input` 端口标签只能写成图下注释；同一展示切面的依赖布局能够在线旁显示它。原质量回退却把 `attached` 归属清单的不同枚举顺序误认为归属不同。

现在归属分区按各自成员集合比较。仅对比较用副本排序，不改变返回图的顺序，不去重，也不排序调用记录、操作数或边内成员。原有绑定检查继续执行。

回退候选同时沿用架构投影的代表层、绑定行和源码标题设置，避免两个候选使用不同展示默认值。显式用户设置仍覆盖默认值。节点、调用、绑定和 canonical 分区保持相同，依赖布局的几何和流程方向可以与所请求的架构编排不同；界面已有状态说明会指出回退。

这项修复同时作用于 StateStack 向上和向下概览，没有模型类型判断。两者均消除了端口标签问题，图幅从 874 × 657 变为 512 × 761。向下线长从 2531.7 降到 2030；向上线长从 1963 增到 2030，约增加 3.4%。质量回退解决的是标签可读性，不保证各项几何指标都减小。两者交叉均为零。

## 核验与当前边界

全量 95 组、1061 项测试通过，架构编排专项为 22 项。34 张新增 SVG 通过独立节点、边绑定、完整归属、摘要、正交路径和实际障碍审核；浏览器文字测量没有发现越界。StateStack 实际完成概览 9/7 → 详图 11/8 → 返回 9/7 → 展开后续调用 12/8，三个实际导出与正式捕获逐字节一致。所有新增状态均验证保存重开 SVG 一致；所有新增输入均验证源码节点和边仍可完整投影。

本轮新增收益来自普通状态程序，Transformer 两档外观没有新的变化。重复结构的代表调用、后续调用卡片及外围源码框仍是下一步改进对象；将继续使用上述跨语义条件审核，不能直接套用专用层的坐标或省略事实。双状态视觉收敛总目标尚未完成，3371 节点同时展开的巨型 SVG 性能仍未验收。
