# 外部输入在使用位置附近布局

本轮从专用参考中提取“把上下文来源与消费关系组织清楚”的通用方向。实现不读取模型名称、案例 ID、源码哈希或参考图坐标；Transformer 只参与评价。

## 规则与不变量

只移动现有的输入接口，不创建副本、引用节点或新依赖。原始 IR、源码归属、输入身份、每次使用及操作数槽位保持不变。接口出现在画面中部或下部，不表示它在此处生成或较晚提供；实际界面点选该接口可查看说明和全部使用记录。

候选来自无输入依赖的独立接口，至少有两条可见使用，目标位于已展开的同级区域内。全部使用必须是无条件的普通数据、别名或接口绑定；未知、可变、状态、观测身份、runtime-only、条件和循环边界不授权移动。SCC 保留现有布局。已有旁路、反馈、布局次序及非普通连接不借此改变。

接口接近实际消费者的中位位置，尝试区域左右外侧，检查同级盒子的间距；估算接近成本至少减少 15% 才形成候选。保留两个主入口（若入口不足三个，至少保留一个），优先处理使用更多的接口，每个父区域最多移动四个。负坐标通过平移同级区域解决，父外框按新边界重新测量。

估算不等于布线收益。论文画布的角色状态只增加一次完整路由试验，并冻结此前已经选择的等级间距、入口带、分支列、上下文通道及代表外框策略。只有逻辑展开集合、图元、边、原始绑定和 accounting 完全一致，且实际线长至少下降 10%，才允许宽度和面积最多增加 12%。高度、交叉、无关接触、异值重合、失败路由、未放置标签、字号和约束冲突均不得退步。保留已实现的入口关系、分支列及输入带。

已有上下文入口仍保留原侧端口。输入移近后，若真正 SVG 中出现一条无障碍的水平直线，可以由这条直线实现该入口，不再要求它绕行纵向通道。此情况单独标为 `direct-docked-entry`，由独立 XML 审核检查唯一源节点、原边、参数槽位、直线和目标侧端口。

`paperInputDocks:false` 关闭自动试验；显式 `true` 供候选诊断使用，不代表已经通过自动审核。手动位移禁止替换；打印视图不采用本规则。手动展开仍保留请求的逻辑前沿，必要时拒绝几何候选。

## 结果与仍未完成的目标

| 输入 | 图元 / 边 | 画幅前 → 后 | 线长前 → 后 | 交叉前 → 后 |
|---|---|---|---|---|
| Transformer | 86 / 94，保持 | 2066×3776 → 2230×3776 | 62647.6 → 55671 | 55 → 47 |
| 陌生多分支 BraidedInputs | 38 / 40，保持 | 1462.46×1732 → 1602×1732 | 20774.2 → 16936 | 10 → 9 |

两者无关接触均保持 0。宽度分别增加约 8% 与 10%；这是以画幅换取较短路径的明确取舍。

LateInputs 的试验虽缩短线长，但高度与宽度增加过多，保留原 SVG；其原有一个端口标签需附注的问题没有解决。BraidedInputs 的更深状态仍可展开为 71 个图元、66 条边；该状态的移动候选新增两个无法放置的标签，被拒绝。条件、未知调用、状态修改及混合结构的回归图保持不变。

实际视觉对照仍显示：通用 Transformer 的来源外框偏多，列间与层间仍有长线，阅读方向、语义组织和角色表达与专用参考有差距。此次优化没有改变语义认证，也不代表已经形成与专用图充分对应的中间折叠状态。

原始源码投影再次恢复 3371 节点、3663 边，全部 ID 和 IR 不变；此检查没有验证数千节点同图路由或浏览器流畅性。完整参考对应、主图/详图协同规划、来源外框、长路径、未见状态与路由组合及大图性能继续保留为未完成目标。
