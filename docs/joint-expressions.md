# 主图与详图的有界联合选择

当前新增一种显式的表达规划：对同一个局部范围，实际渲染“在主图中展开”和“主图保持紧凑、增加独立详图”两种候选，按直接表达的目标、总面积和图数选择。原有顺序添加详图的默认行为保留。编辑器在可缩放画布、角色关系粒度提供“规划主图与详图”；CLI 使用 `--joint`。

## 依据与边界

规划首先冻结初始作用域和证据模式下的表达目标。接口、计算关系、选择、状态、条件、共享身份等目标按原始实例分别计数，代表实例不能替其他实例兑现目标。候选声称的目标仅用于安排试算；实际 SVG 中的核心节点、有效路径、原始操作数、结果槽和条件绑定才决定覆盖。质量不合格的图不能获得覆盖。

每轮最多比较两个相关候选。主图候选来自通用局部角色、关系与运算路径机会；详图候选来自通用作用域和局部关系边界。内联展开还必须通过已有主图角色、摘要、边界及几何保护检查。自动主图已经选中的角色与路径被带入候选，避免试算从旧状态重新开始。此前已经兑现的直接目标不允许丢失。

选择按重要边界目标、关系目标、计算目标的优先级向量，除以“实际总面积倍率 × 图数倍率”。结果记录候选状态、实际几何、增益与丢失目标、资格和选择原因。未选中的合格候选也保留真实 SVG；预算允许时可复用已渲染候选。没有任何生产决策读取模型名称、参考案例 ID、源码哈希或专用图坐标。

这是有界局部搜索，尚未实现全部摘要、容器、布局方向与图组的全局联合优化，也不保证优于顺序策略。预算耗尽时，探索一种替代表达会占用原本能生成更多详图的试算机会。该限制在下面的 Transformer 对照中实际出现，因此此功能保持显式启用，不能据本轮结果宣称专用参考收敛。

## 同预算实际结果

冻结旧版本 `424233c`，相同输入、相同初始状态，每组至多三张图；小案例至多四次候选渲染，Transformer 至多两次。两组均捕获每次实际渲染，包括落选候选，没有从选中结果重建“伪候选”。

| 输入 | 旧 → 当前直接覆盖 | 图数 | 当前 / 旧总面积 |
| --- | --- | --- | --- |
| SourceMosaic | 9/9 → 9/9 | 2 → 1 | 0.613 |
| MixedWeave | 17/43 → 20/43 | 3 → 2 | 1.462 |
| NestedWorkshop | 28/28 → 28/28 | 3 → 3 | 1.000 |
| BrokenWorkshop | 27/27 → 27/27 | 3 → 3 | 1.000 |
| GuardedRelayWorkshop | 18/24 → 18/24 | 2 → 2 | 1.000 |
| Transformer | 49/1855 → 41/1855 | 3 → 2 | 0.901 |

SourceMosaic 主图由 6 节点展开到 11 节点，省去一张独立详图。MixedWeave 同时选中内联角色路径和独立详图，增加覆盖但总面积增加 46.2%；图数减少不等于画面成本全部降低。Transformer 两组主图均为 80 节点、91 条线、2166 × 3656，SVG 字节相同；当前图组少兑现八项目标。这些分母是当前作用域逐实例直接表达的目标，不是总体架构准确率，也不是专用图相似度。

三份新静态输入覆盖共享调用、嵌套自定义曲线、门控、TopK 结果槽、未知调用与条件保护。不执行追踪，不宣称支持任意 Python 或继承方法抽取。条件案例、长链和大模型仍有未兑现目标。

## 审核

- 630 项测试、51 条命令全部通过；九项新增测试涵盖真实表达竞争、混合选择、已有自动细化、错误操作数、保护边界、预算、不可变性及保存导出。
- 84 张正式 SVG 独立核对 XML、路径、端口、原始绑定、区域切边和逐对象去向。Python 独立重算每个面板覆盖、每轮增益、面积成本及实际选择，不导入 JS 规划器。
- 88 张实际 SVG（含编辑器导出）由浏览器按原始字号测量文字和标签边界。落选图仍纳入检查，不能只核对选中结果。
- 实际编辑器使用文件选择器完成导入、规划、保存、重开、详图重开与返回；SVG 与独立渲染逐字节一致。改变主图状态后旧“已规划”标记消失。读取大文档时分段取导出文本，避免浏览器工具响应上限造成证据截断。
- 小例源码视图保留全部 16 节点、14 条边。固定 Transformer 源码投影仍保留 3371 节点、3663 条边；这不证明数千节点完整 SVG/UI 性能。
