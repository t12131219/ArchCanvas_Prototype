# 联合表达规划的投影预检

目标仍是由通用局部事实形成可继续展开的语义架构状态，并在该状态接近专用图的模块逻辑和视觉组织。此次改善联合规划的候选调度，修复上一阶段有限路由预算被无效主图展开占用的问题。生产决策不使用模型名、案例 ID、源码摘要或参考坐标。

## 实现与边界

`diagram-set/4` 在主图内联候选路由前，执行真实 `E.project` 未路由投影。角色展开必须实际 `expanded`，角色路径必须实际 `exposed`；被保护、预算暂缓或没有新增潜在目标的投影不消耗候选路由次数。潜在目标检查核心节点和真实边 ID，包括计算的所有输入绑定。此处只决定是否值得路由，不证明覆盖或几何质量；最终仍从实际 SVG 的操作数、结果槽和物理路径核验。

每轮只比较同一个机会的主图展开与独立详图。若另一种形式无法展开，先评估当前形式，其他范围在后续轮次调度。不能把无关小详图塞入同轮竞争：开发中的该做法曾使小图挤掉完整嵌套计算，已移除，并以回归测试保护。

投影最多 24 次，超出记录 `projection-budget`，不假装完成覆盖。候选路由用尽后，可以重新评估已渲染、先前未选中的结果，不重复路由。原有绑定、摘要、角色、关键边界和布局质量保护保持。保存文档、CLI 导出均保留预检及暂缓记录。

这仍是有界局部搜索。预检可排除确定无效的请求，但无法预测完整路由质量，也不保证找到全局最优表达。默认顺序策略保持；编辑器通过“规划主图与详图”显式启用联合规划。

## 实际对照

冻结基线为 `eac5953` 的联合规划，同一输入、相同图数上限和候选路由预算。完整数据及面积见 `verification/joint-preflights/current/review.html`。

| 输入 | 直接表达目标：旧 → 当前 | 候选路由次数 | 图数 |
|---|---|---|---|
| SourceMosaic | 9/9 → 9/9 | 2 → 2 | 1 → 1 |
| MixedWeave | 20/43 → 25/43 | 4 → 4 | 2 → 3 |
| NestedWorkshop | 28/28 → 28/28 | 4 → 2 | 3 → 3 |
| BrokenWorkshop | 27/27 → 27/27 | 4 → 2 | 3 → 3 |
| ConditionalWorkshop | 11/28 → 11/28 | 3 → 2 | 2 → 2 |
| Transformer | 41/1855 → 49/1855 | 2 → 2 | 2 → 3 |

MixedWeave 的收益来自新增 `self.collect` 独立详图，主图仍为 21 节点，总面积增加约 15.1%。Transformer 恢复到更早顺序规划的覆盖水平，主图仍为 80 节点、91 边、2166 × 3656，前后 SVG 字节相同，总面积增加约 11%。目标分母是当前范围逐实例直接表达目标，不是架构正确率。没有主图与专用参考接近程度改善的证据。记录的运行时间受并行负载影响，不作为性能基准。

## 已完成审核

- 635 项测试、52 条命令全部通过；新增五项检查无效投影不占路由预算、无关小图不挤掉完整计算、预算暂缓角色不算覆盖、错误物理绑定不能被投影承诺覆盖、零预算不运行投影。
- 87 张实际 SVG，含未选中试算；独立 Python 审核重算物理覆盖、原始绑定、边界和每轮选择。另有独立投影重放器，不导入规划器，重放 12 组、13 次实际投影并核对预检结论。
- 92 个原始字号 SVG 面板在真实浏览器测量，2127 处节点文字、117 处端口文字无越界。目视抽查陌生计算、混合、嵌套、未知、条件及 Transformer/专用参考；截图和局限见 `visual-review.json`。
- 真实编辑器完成导入、规划、保存重开、两份独立详图往返、改变粒度后的旧计划失效显示；导出与程序生成 SVG 字节相同。源码小例 16 节点、14 边全部保留。
- 固定 Transformer 输入源码投影仍保留全部 3371 节点、3663 边，原始 IR 未变。此项不证明几千节点完整 SVG 路由和浏览器交互性能。

## 复现

先运行 `python tools/freeze_joint_preflights.py`，再运行 `node tools/audit_joint_preflights.cjs` 和 `node tools/audit_joint_preflights.cjs --large`。实际编辑器操作保存至当前阶段后，运行 `node tools/audit_joint_preflights_ui.cjs`、`python tools/check_joint_preflights.py`、`python tools/build_joint_preflights_review.py`。在真实浏览器使用保存的字面探针检查 `text-qa.html`，保存原生文字与目视审核记录。完整单元测试使用 `python tools/run_local_tests.py`，当前阶段保留全部 52 份命名日志。

`python tools/summarize_publication_checks.py` 核对本阶段证据，退出码 2 表示完整目标尚未完成。后续仍需主图语义和参考视觉收敛、摘要/容器/图组的更完整联合规划、更广的未见状态/控制/路由/副作用组合，以及数千节点 SVG/UI 验收。
