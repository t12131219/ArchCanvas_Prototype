# 按已认证分支确定局部旁路

此次把专用架构图的一个版式经验落实为通用局部原语：旁路围绕它实际跳过的计算区域，而非始终跟随较大的源码归属容器。选择不使用模型名、类名、案例 ID、源码哈希或参考坐标。源码归属仍保留在原来的 `design_route.owner`；新的可见分支范围单独记录在 `layout.local_bypasses`。

展开模块的标题区域继续允许穿行。真实节点、折叠模块、未知节点、标题内的固定参数和无关展开模块的内部仍是障碍。

## 资格与退让

1. 必须已有源契约认证的 bypass，以及实际实现且审核通过的原旁路收据。原有冲突或 deferred 收据不能因新候选而被默认为通过。
2. 精确 skip 生产者、结果槽、canonical add 接收端及可见端点必须与契约一致；不接受 bundle、条件边、迭代边、状态边或已有上下文通道。
3. 契约分支路径中的全部节点必须有可见映射。遇到未知、控制、状态、buffer、可变操作、条件节点或 phi 时退让。已折叠到当前 Add/Norm 阶段的最终分支操作可留在该阶段，但不得把其他计算映射到 skip 来源。
4. 依据画面归属树，取分支代表的最外层可见包围框，止于起终点的共同祖先范围。包围框必须完整处于两个端点之间。
5. 在该边界外侧尝试最多四条近邻直角通道；每张图最多检查六条旁路。每条线保留独立物理端点、操作数和原始边记录。
6. 只有真实障碍检查通过，且不增加交叉、接触、重叠、画布、字号问题、路由失败或未放置标签，同时减少线长，才允许接受。既有直接表达和已经实现的约束必须保留。其余候选保持原路由。

新收据为 `local-bypass-lane`。审核实际四点正交路径、相对分支边界的位置、完整分支纵向跨度、来源/结果槽/汇合端及 canonical 分支见证。它没有放宽旧的 `reserved-lane` 审核；状态和循环通道继续使用原机制。空白带压缩后再次根据最终几何审核，避免以过期坐标宣称兑现。

初次独立审核发现 TailMosaic 中原本已冲突的旁路也可能进入候选；现已加入“原约束实际应用”的资格限制，并以反例验证。该既有冲突仍明确保留，没有凭短路径将它转为成功。

## 正式结果

使用提交 `58124c7` 冻结的真实实现和当前完整管线，对相同输入与相同展示状态进行前后绘制。

| 状态 | 图元 / 连接 | 交叉：前 → 后 | 线长：前 → 后 | 局部旁路 |
|---|---:|---:|---:|---:|
| 主图 | 65 / 76 | 12 → 12 | 38405.7 → 37341.7 | 2 |
| 第一张详图 | 44 / 48 | 3 → 3 | 15340.3 → 15340.3 | 0 |
| 第二张详图 | 64 / 63 | 9 → 9 | 26180.2 → 24976.2 | 1 |

主图线长减少约 **2.77%**，第二张详图减少约 **4.60%**。主图画布仍为 **1968 × 3342.5**，没有新增节点侵入、无关接触或路径重叠。两个前馈旁路现在靠近实际计算区域，减少了跨大容器绕行。注意力路径含 phi，未通过本轮保守资格检查，保留原通道。没有按其名称追加例外。

同一规则也用于 MixedWeave、TailMosaic、EscapingTail、InterruptedTail 和 ConditionalTail；在未知或条件组合中，仅独立满足资格的分支得到调整。18 个小图状态和三个固定大图状态共生成 42 张对照 SVG。此次没有重新规划图组；主图和两张详图是已有的固定状态。

这是局部走线改善。阅读方向、容器组织、返回分支和重复实例摘要仍与专用参考不同，不能称为整体目标完成。通用图的该中间语义状态之下仍保留更细展开能力。

## 验证与复现

完整本地回归为 **71 组、814 项通过**，其中八项针对局部旁路。独立 SVG 审核及其输入/实现哈希保存在审核产物中。独立程序核对实际 SVG 路径与节点、正交性、节点侵入、交叉/接触/重叠、物理端口、逐节点/逐边 accounting、原始绑定、局部范围见证和直接表达；错误槽、条件、端点、分支范围及见证五种损坏必须被拒绝。

MixedWeave 另验证保存重渲染、禁用新规则后与冻结实现一致、折叠后恢复相同 SVG，以及原始源码投影的完整 ID 集合。Transformer 原始源码投影仍可恢复 **3371 个节点 / 3663 条边**，canonical IR 未改变。本轮没有重新生成该整张原始源码 SVG，也没有测量浏览器性能。
