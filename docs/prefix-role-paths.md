# 已证明的前置路径与角色组成可逆语义阶段

本轮扩展通用“角色与相邻路径合组”：此前支持“角色 → helper”，现在也支持“helper → 角色”。选择依据是原始证书、独立路径证明和精确使用关系，不读取模型名、类名、案例 ID、源码哈希或专用坐标。Transformer 只作为对照输入。

入口：论文视图 → 可缩放画布 → 角色关系 → **角色与相邻路径合组**。沿用 `paperRolePathStages`，默认关闭；自动图组仍可按 owner 选择合组范围。关闭规则、源码视图、打印、其他展示粒度及明确的角色/helper 细化请求保留原行为。脚本资源版本同时更新，避免编辑器沿用缓存中的旧规则。

## 证据和边界

- 角色必须由 canonical IR 的真实附着证书及精确角色键指向当前原始运算；证书覆盖全部阶段成员。
- helper 必须已有独立重新验证的 `dependency-path-summary`，包含二至六步运算，与角色处于相同源码和展示作用域。
- helper 只有一个外部输出，直接进入角色，或经同作用域的独占普通赋值别名进入角色。每个桥接别名只有一个输入、一个使用，没有运算、结果槽选择、条件、身份或运行观测。别名仍为 canonical 成员，保存完整内部边和切边。
- helper 的配置和形状读取仍保留在路径证明中。角色的参数读取保持独立附注；角色结果的多个外部消费端逐条保留。
- 未知、状态、副作用、条件、运行专属、身份、其他认证角色边界及明确展开请求阻止合组。规则不跨这些边界推断透明连接。
- 若 helper 输入端直接相邻另一个角色，仍归此前“角色 → helper”候选。即使该候选因证据损坏而拒绝，也不从反方向接管同一 helper。完整回归发现并纠正了这个冲突。

陌生源码 `PreparedCurve` 的真实前馈证书支持 `Identity → Dropout → Linear`；改名并增加第二层赋值别名后仍使用同一规则。源码中让 helper 结果逃逸或插入未知调用后，完整证书不再成立，系统不合组。额外的候选级破坏检查保留证书，分别检验桥接别名和 helper 额外使用、结果槽、更改角色引用、受保护成员、伪造证明及作用域变更，防止将“源码没有证书”和“候选确实拒绝逃逸”混为一项证据。

## 展开与直接表达

摘要显示角色名称及真实操作序列。双击阶段恢复 helper 摘要和角色操作，再双击 helper 恢复具体运算。单击阶段减号可以从深层直接收起，同时清除内部的展开请求。原始 IR、构造配置、参数、操作数和结果槽不变；这个阶段没有融合、纯度或等价承诺。

真实编辑器导出为 7 图元/5 边 → 9/6 → 11/7；深层保存重开与 SVG 逐字节一致，收起及恢复自动粒度后与初始 SVG 逐字节一致。源码视图“展开全部”显示 15 个原始节点、12 条边，全部 ID 与实际路由独立核验。另一个条件/未知/GRU 混合输入的实际 UI 导出也与正式 SVG 一致。

被摘要隐藏的操作及其关系目标仍为 `unfulfilled`。主图收起三个输出投影后，主图直接目标从 24 减至 21，相关直接表达转由已有详图承担；摘要不冒充直接操作覆盖。选中图组仍直接覆盖 **74 项**，没有丢失此前覆盖的目标，也没有新增覆盖。

Transformer 三处前置路径 `transpose → copy → reshape` 与随后已认证的输出投影合组。主图高度减少约 5.4%，线长减少约 4.0%，但交叉增加两处；这是当前明确保留的代价。两张选中详图的 SVG 逐字节不变。实际图组规划另测了一个细化候选，因交叉成本拒绝；没有把被拒候选算作成果。正式可复现审核将本轮额外细化候选限制为一次，并报告实际限制。

展开会增加容器和高度：PreparedCurve 深层为 336×1020，大于基线 300×736。主图紧凑和详细证据展开不是同一个几何目标。

连线继续允许穿过展开模块标题，包括 attention 外框；具体运算节点、折叠模块和端口标签仍作为障碍。独立 SVG 检查没有发现侵入具体节点或无关容器主体。浏览器原生字体检查覆盖 29 张正式 SVG、1401 段文字、71 个端口标签，无越界。

视觉复查仍能看到通用图与专用参考在阅读方向、残差分组、helper/返回细节密度和跨区长通道上的差距。本轮减少了相邻辅助盒子，尚未达到专用参考的整体表达。不能以单个更紧凑的状态宣称完整目标已完成。

## 验证和复现

- 65 组命令、759 项测试通过；包括此前角色/后续路径测试及新增六项前置路径测试。
- 五份陌生源码重新抽取，未执行未知调用。29 张正式 SVG 和七份实际 UI SVG 独立核验成员、证书、别名、切边、绑定、结果槽、路由、几何与直接目标。
- 审核器按原始路径重建全部终端使用，支持普通别名后的多消费端；物理结果槽与 `resolved_source` 对应，并与未收缩源码事实解析到同一值及槽。故意改错结果槽、目标操作数或删掉一个消费端的来源记录，必须被拒绝。
- 大图源码投影仍为 3371 节点/3663 边，全部 canonical ID 可见。这没有验证数千节点完整 SVG 路由或浏览器交互性能。
