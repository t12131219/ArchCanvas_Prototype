# 折叠依赖摘要的逐算子输入引用

继续维护两个评估目标：F0 是接近专用完全折叠图的语义概览；F1 是接近专用展开图的角色与局部计算状态。两者都不是原始源码的最细展开。本轮改进只影响折叠摘要的文字组织，没有增加 Transformer 专用识别或坐标模板。

## 表示与证据

已有依赖 DAG 摘要把内部公式、读取消费和外部输入消费分开打印。同一输入因此多次占用独立附注。新候选把每个已知使用直接放在对应算子行：

```text
Result #4 · tanh
Dependency DAG · operand uses
#1 device-cast ← arg:0=input1("x"); receiver=read1("self.offset")
#2 mult ← 0=#1; 2=#1
#3 add ← 0=input1("x"); 2=#2
#4 tanh ← arg:0=#3
```

每个内部结果只编号一次，源结果槽和消费槽继续保留。`readN` 根据规范 IR 的读取节点身份分配；`inputN` 根据输入接口身份分配，不依赖标签拼写。即使两个不同节点的属性文本相同，也不能合并编号。

这里的读取节点不是“运行时读取次数”或“值相等”的证明。抽取器可能已经把重复属性语法归到一个读取节点；本轮不会增强该事实，也不推断不可变、纯函数、别名相等、执行顺序或融合。编号只服务于已有证据的展示。原始 `local_pipeline` 合同、操作、边、源码和切边完整保留；证据面板可以查看精确记录。

## 测量选择与边界

默认仅对可缩放画布 stages、最多 128 条可见边、没有用户位移且有折叠源码读取摘要的图尝试一次完整候选布局。保留既有前沿、对象去向、精确边描述、直接表达目标、已兑现摘要目标、已应用约束和已实现关系；要求面积严格减少，高宽和线长不增加，交叉、非关联接触、歧义重叠、路由或标签失败不增加，字号不缩小。任一条件失败即保留原表示。

`paperReadBindingRows:false` 退出；显式 true 只供检查候选表示，不代表自动测量接受。打印、角色详图和有用户位移的状态不默认启动候选。这是局部依赖关系的通用表达选择，不根据类名、模型家族、案例 ID、参考图坐标或源码哈希选择。

10 个新的物理源码入口经静态抽取，覆盖共享中间结果、不同输入使用、元组打包与 getitem、长属性名、未知邻居、GRUCell 状态邻居、条件邻居、共享模块调用以及未知调用链。未知、状态、条件和共享调用的原有身份及连接保持原样。新增 12 项测试包含损坏收据、遗漏实际文字、改名、保存重开和原始源码投影；996 项测试、90 组全部通过。

实际反例 WideLabelWorkshop 的最终算子名称较长，新标题使整体从 408×418 变成 408×422。自动测量拒绝候选，保留与基线逐字节相同的 SVG。正式审核保留强制候选以公开这个失败结果。
