# 局部认证角色细化

`role-frontier/2` 在既有角色视图中增加局部选择：`paperRoleDetails` 保存要进一步
解释的认证区域 ID。它消费该区域已有证书的角色引用，不按模型名称、类名、
case ID、源码哈希或已知家族选择规则。父区域和子区域分别保留自己的证明
所有者、适用范围、未证明属性及角色映射，不把两份证书合成更强的证明。

默认仍采用原来的外层认证前沿。显式选择子区域后，普通源码 helper 可以打开，
该区域按自身的角色路径组织；其余认证区域保持摘要。多层请求按来源层级
处理，不能跳过未选择的中间认证边界。未知、条件、控制、可变、共享身份、
运行观测及重复边界不能穿越。源码独有角色视图也不得穿过 runtime-only 区域。
预算不足、不可见或手动收起会记为 deferred，不声称内容已经展示。

编辑器中选中认证复合区域，可使用“展开本区域已证明的角色”，再用“收起本
区域的角色细化”恢复默认。双击及“展开全部”仍提供更细的源码展开。图文档
保留选择和具体 open 状态，保存、重开、收起均可复现。

这一步提供的是可组合的语义状态选择，不是自动选择最优整图状态。可缩放
画布继续遵守既有约定：保留用户请求的细节，明确报告面积或路由失败，不
静默替换成总览。需要局部详图时可使用“模块详图”选择该区域。

## 结果与反省

基线来自 `eeb68e2` 的 140 份原始文件，保存在
`verification/local-relations/iteration-22-before-role-details`。六个混合、未知、
残缺、条件及共享样例，加上 SameSource 和 Transformer，共八个默认 SVG
与上一轮逐字节相同。陌生证书结构、多层细化、改名、守卫、缺失证据及资源
限制另有单元测试；没有为 Transformer 添加生产专用分支。

SameSource 从 11 图元 / 10 边，局部细化为 17 / 17；真实 UI 的更深展开为
36 / 40（具体 open 集合与命令行的精简全展开 34 / 38 不同），重开恢复 17，
收起恢复 11。两者均保留规范 IR、每个操作数和底层角色证明。局部细化增加
了可见信息，也使该图从 0 交叉增到 2；不是几何优化。

Transformer 默认仍为 100 / 106、2588 × 4530 px、57 交叉。只追加一个嵌套
区域后为 114 / 127、2332 × 9532 px、98 交叉，超过面积预算；追加三个区域
后为 142 / 169、2332 × 11224 px、219 交叉，同时出现路径重叠。失败实验
保存在审核页，不能计作整图通过。单独的局部详图为 22 / 28、658 × 1958 px、
3 交叉，几何检查通过；它不能证明整图接近专用参考。

377 项测试通过。审核分别核对实际 SVG、独立角色所有权、浏览器文字和
真实 UI 交互；几何失败单列。首次绘图尝试保存在 `verification/role-details/attempt-1`，
最终产物见 `verification/role-details/current`。历史基线和历史报告不重新盖章。

```sh
python3 tools/run_local_tests.py
node tools/audit_role_details.cjs
python3 tools/audit_local_svg.py --role-details
python3 tools/audit_role_detail_receipts.py
python3 tools/build_role_details_review.py
node tools/audit_role_details_ui.cjs
python3 tools/summarize_publication_checks.py
```

最后一个命令返回 2，表示本轮证据一致但整体目标未完成。下一步应把实际
面积、角色覆盖和跨区域连线成本引入候选语义状态及图组选择。不能通过增加
展开节点数推断视觉收敛，也不能用局部详图的成功掩盖整图失败。

审核工具会复用同一生产实现的精确哈希产物，原始生产脚本与报告独立保存在
`attempt-2`；新增的通道审核字段从原始图文档读取。缺少产物时重新生成；
`node tools/audit_role_details.cjs --fresh` 强制重新布局全部状态。浏览器缩略图
测量曾出现亚像素缩放误差，另存初次测量；最终逐张在 SVG 原始比例复核，
检查 1038 处文字，其中 1009 处矩形内文字均通过，符号附注不套用矩形包含。
