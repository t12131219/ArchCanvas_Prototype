# 角色及后续运算的可展开阶段

本轮把实际语义主图中的一种局部表达做成通用能力：一个已认证角色及其独占的普通一元后续运算，可以组成可展开的展示阶段。摘要明确打印每一步操作，例如 `GELU → Dropout → Identity`。这不是算子融合、纯函数证明或输入输出等价判断。

编辑器在“论文视图 → 可缩放画布 → 角色关系”提供可选开关“角色与后续运算合组”，保存到 `paperRoleOperationStages`。默认关闭；本轮七个输入的默认 SVG 与冻结基线 `3e59b2f` 逐字节一致。此阶段没有改变默认粒度选择策略。

## 通用判据

角色必须由已附着的证书及精确角色路径指向当前原始操作。后续最多三个操作，全部位于相同原始作用域及证书成员范围；每一步有唯一普通数据输入，前一步只有一次使用。额外输入仅允许明确的参数读取。

未知调用、条件、状态和副作用、运行观测、共享身份、其他角色边界、选择结果槽及中间结果外用等情况阻止相应合组。明确要求查看角色内部的请求优先，不把该角色再次收进摘要。生产逻辑不读取模型名称、案例 ID、源码哈希或参考坐标。

函数式角色允许缺少构造配置；仅读取节点自身的 `constructor` 元数据，缺失时记录为 null，避免误读对象原型。该边界有独立回归测试。

原始 IR 不变。每个阶段保存有序原始运算及构造配置、完整成员、内部边和精确切边；当前端口仍对应原始操作数及结果槽。双击阶段可展开，收起和保存重开均可恢复原 SVG。

## 实测收益和代价

| 输入 | 图元 / 边：基线 → 合组 | 尺寸：基线 → 合组 | 独立核验的直接表达目标 |
| --- | --- | --- | --- |
| QuartzPath | 8/6 → 6/4 | 272×736 → 300×562 | 7 → 4 / 7 |
| RenamedPath | 8/6 → 6/4 | 268×736 → 300×562 | 7 → 4 / 7 |
| MixedStageWeave | 19/16 → 17/14 | 674×1100 → 674×1008 | 16 → 13 / 16 |
| Transformer | 80/91 → 78/89 | 2166×3656 → 2166×3564 | 33 → 29 / 1855 |

Transformer 的两个阶段均为 `ReLU → Dropout`，交叉从 47 减至 46，主图面积减少约 2.5%。陌生和改名案例使用相同规则；完整原始运算在展开状态恢复。带未知调用和 GRU 状态接口的混合图保留这些边界，条件案例仅合并独立的无条件部分。中间结果逃逸和未知调用案例保持原 SVG。

摘要减少了直接显示的原子计算，因此不能宣称原子覆盖提高。被隐藏运算的目标仍明确标记为 `unfulfilled`，并记录缺失原始节点。QuartzPath 合组后宽度增加，展开后还会增加容器及空间成本。这些代价都保留在报告中。

## 验证

- 646 项测试、53 个命令通过，新增 11 项合组测试。
- 25 张正式 SVG；独立 Python 审核重新抽取六个源码案例，核验角色证书、成员、运算顺序及配置、切边、操作数与结果槽、物理路径、几何及直接表达目标。
- 30 张实际 SVG 在浏览器原生 DOM 中检查：1082 段节点文字、48 段端口文字均位于对应图形内。
- 真实编辑器完成导入、开关、凭据检查、双击展开与收起、保存重开、最细源码视图及返回；混合图和 Transformer 实际导出与正式 SVG 一致。
- 同一 Transformer 原始输入仍可投影出全部 3371 个节点、3663 条边。此项不证明数千节点完整 SVG 路由及浏览器交互性能。

## 尚未完成

完整用户目标仍未完成。目视全图可见，通用图仍有密集的内部路径、较长的跨区通道，层级和视觉重点也与专用参考有明显差距。本轮仅改善两个前馈阶段，不能据此宣称已经接近专用图的整体表达。

后续应让语义阶段、容器边界及图组选择共同参与实际尺寸评估，区分“架构关系已清楚表达”和“原始运算直接显示”两类目标；根据局部证据组织投影、变换、汇合和上下文通道，在需要细节时恢复原操作。还需扩大未见组合验证，并单独验证数千节点完整渲染及交互。
