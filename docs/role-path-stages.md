# 角色与独占后续路径的两级语义阶段

本轮把“一个已认证角色”和“其独占使用的已证明 helper 依赖路径”组合成一个可展开阶段。它用于形成合适的中间语义状态；继续展开仍恢复角色、helper 和具体运算。不是算子融合或输入输出等价判断。

入口：论文视图 → 可缩放画布 → 角色关系 → **角色与后续路径合组**。状态字段为 `paperRolePathStages`，默认关闭。本轮七个输入的默认 SVG 与冻结基线 `1b9fa9c` 逐字节相同。

## 通用判据

角色必须由原始 IR 中附着的完整证书及精确角色键路径指向当前原始操作，证书覆盖阶段全部成员。后续 helper 必须已经通过独立的依赖摘要证明检查，且是至多六步的路径；角色与 helper 位于相同原始和展示作用域。角色结果只有一次使用，helper 只有来自该角色的一个外部输入。内部形状和配置读取仍是独立事实。

条件、未知调用、副作用、运行观测、共享身份、其他认证角色边界、额外输入、中间结果逃逸或被选择的结果槽阻止合组。规则不读取模型/类名、案例 ID、源码哈希或参考坐标。模型改名和 helper 改名使用相同规则。

阶段保存原始成员、内部边、每一步运算及构造配置、完整 helper 证明和原始切边。原始 IR 不变；参数读取保持附注去向，数据切边仍对应实际操作数和结果槽。

## 展开与还原

1. 摘要打印角色名及真实运算序列，例如 `GELU → Dropout → Identity`。
2. 双击阶段标题，恢复角色操作与 helper 摘要。
3. 双击 helper 标题，恢复它的具体运算；源码视图仍可查看全部原始节点。
4. 从深层状态收起阶段时，同时清除它内部的展开请求，避免残留 helper 请求使摘要消失。明确的独立 helper 或角色细化请求仍优先。

真实编辑器验证了开关、两级展开、从深层直接收起、保存重开、源码完整展开及返回导入；实际导出与正式 SVG 一致。最细源码检查仍为 3371 个节点、3663 条边，全部原始 ID 可见。这不证明数千节点完整 SVG 路由与浏览器交互性能。

## 实测收益和代价

| 输入 | 图元/边：基线 → 合组 | 尺寸：基线 → 合组 | 交叉 | 直接表达目标 |
| --- | --- | --- | --- | --- |
| PrismPath | 7/5 → 6/4 | 300×644 → 300×562 | 0 → 0 | 5 → 4 / 7 |
| MixedPaths | 21/17 → 20/16 | 685×1294 → 685×1294 | 0 → 0 | 16 → 15 / 18 |
| Transformer | 80/91 → 73/82 | 2166×3656 → 1968×3594 | 47 → 42 | 33 → 24 / 1855 |

Transformer 中九组 `Linear → reshape → transpose → copy` 使用同一规则形成阶段；面积减少约 10.7%，但总线长从 49186.5 增至 52408.6（约增加 6.6%）。局部合组会改变全图排布，不能只用面积或图元数量评价收益。MixedPaths 的全图高度未改善，线长也略增。

被隐藏运算及需要这些运算直接出现的关系目标仍为 `unfulfilled`；摘要不冒充完整原子表达。PrismPath 深层展开增加容器，高度为 942，而基线为 644。这些成本保留在独立报告中。
