# 通用重复区域与代表调用外框

目标是在同一份通用事实图中减少重复外框，保留可继续细化的语义状态。规则依据重新核对的局部重复结构、具体调用身份和真实依赖；不读取模型/类名、案例 ID、源码哈希或参考坐标来选择生产行为。

仅当一个已展开序列有唯一的已证明代表、其余调用完整覆盖于关闭的有序后续摘要、且代表自身不承载接口边、契约、条件、未知、可变、观测或共享身份边界时，代表调用框才可附注到序列框。标题区明确写出 `Detail: source call 1`；模块身份、原始位置、源码与参数共享状态保存在可检查的 ownership 回执中。序列次数不是新增执行证明，结构相同也不表示输出相同或参数共享。`unresolved` 参数关系保持未知。

这项转换只改变画面外框。代表内部的每个操作、语义模块、条件及端口不变；后续调用仍为独立的可展开摘要。展开后续摘要会恢复代表调用框，使多实例边界清楚。聚焦代表本身、选择“保留源码外框”或显式 `paperSampleFrame:false` 可保留框。未知、异构、可变和共享身份序列不被该规则合并。实际源码与 canonical IR 不改写。

默认可缩放画布的角色视图只试画一次候选。验收保持非外框节点、所有边/绑定/条件、展开状态、角色、直接表达及摘要覆盖；仅允许具体代表节点由 visible 转为 attached。还要求面积至少降低 2%，宽高和线长不增加，字号不降低，交叉、无关接触、异值重合、失败路径、缺失标签及约束冲突不增加，并保留原来已实际实现的入口、角色列和上下文沟槽。显式状态、手动偏移及打印不会被自动替换。候选次数有界，不是全局最优或墙钟时间保证。

本阶段以八个已有源码输入检验，新增八项有意义的测试。正式前后图使用同一 IR；底层的调用、配置与源码证书重新检查，不以历史报告证明新的实现。源文件与哈希均保留，生成的完整派生布局不重复进入 Git。

浏览器原生文字测量、真实 UI 操作与目视记录必须单独完成。最后的汇总命令在证据一致但完整目标仍未完成时返回 2。

Transformer 的目标主图从 89 → 87 图元，97 条边不变；2066 × 4028 → 2002 × 3908 px；交叉 57 → 56，仍有 0 处无关接触。三组角色列、三条已实现上下文通道及原有入口组保持。普通同构序列、独立参数序列和交织组合采用同一规则；异构、未知、可变和共享身份案例保留相同 SVG。这里只减少冗余身份外框，未新增语义认证或直接细节覆盖。

489 项回归测试、16 张 SVG 独立审核及来源归属回执检查通过。浏览器在原生比例实测 624 个节点标题/说明和 16 个连线标签：标题/说明未越所属形状，连线标签未越 SVG 边界，字号均不低于 13 px。真实编辑器验证同构序列 9 → 12 → 保存重开 12 → 9，收回 SVG 与主图逐字节一致；源码外框模式恢复至 11 个图元。Transformer 实测 87 → 92 → 87，主图、收回图和 CLI 导出一致。

Transformer 局部展开时的 92 包含恢复的两个代表外框：当前展开状态的外框合并候选会将交叉 55 → 56、线长 66027.1 → 66509.9，因此被拒绝；收回后候选重新通过。不能把每次局部展开都理解为仅增加该局部节点数。`ui-refinement-check.json` 保留这项独立复现，`ui-transformer-expanded-state.json` 明确来自导入前沿与实际双击动作，不声称本阶段完成了 Transformer 全文档保存重开。

目视对照仍可见较多源码外框、条件/输出包装和跨范围长路径；专用参考更集中地表达阶段和计算关系。编辑器同步计算曾导致观察和点击超时，随后操作完成；两次 CLI 状态复现约需 47 秒和 41 秒。这不是浏览器性能基准，当前不能承诺交互流畅。完整数千节点路由性能仍须单独测试。

整体主图与专用参考的语义对应、更多跨范围长路径、语义表达与图组的联合选择，以及未见状态/控制/路由组合仍需继续优化。3371 节点 / 3663 条边的原始恢复检查不证明数千节点完整 SVG 路由和浏览器交互性能。
