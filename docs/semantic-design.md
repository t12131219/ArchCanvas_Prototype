# 通用语义认证与架构版式：方案、实现和审核边界

本阶段把人工绘图经验拆为可复用的语义契约、信息抽象和布局原语。规则由操作身份、值依赖、对象绑定和图结构触发，不按模型名、类名、案例 ID 或源码 SHA 选择架构模板。Transformer 仅是比较基准；源码类名可以作为来源标签显示，不构成架构认证。

## 可行性与目标

人工审图通常包含四项判断：识别哪些计算共同实现一个结构；决定主图保留什么；安排流程、分支和旁路；看图后回查源码。前两项可变为有前提的规则，第三项可变为局部布局约束，第四项需要持续的自动检查与目视审核。

局部残差、归一化、前馈链、标准矩阵注意力、固定模块序列有明确依赖和框架契约，较适合自动认证。任意 Python 副作用、反射、外部工厂、动态路径与未知算子不能统一恢复。系统应在支持的子集内增加表达能力，并为未证明部分保留边界。

链路分为五层，层间有明确责任：

```text
源码 / 构造配置 / 明确输入上的运行记录
  → 原始事实 IR：对象、调用、槽位、条件与来源
  → 语义契约：角色、适用范围、前提和未证明属性
  → 架构投影：可逆折叠、代表实例、观测分组与模块详图
  → 几何布局：主流程、分支对齐、旁路与合绘依赖
  → 实际 SVG 审计 / 浏览器文字测量 / 目视自省
```

布局不得发明角色；折叠不得改变参数共享或调用身份；一次运行不得代表所有输入；语义契约不等于整个程序的等价证明。

## 已实现的通用能力

### 1. 受限构造与串行递推

`semantic_adapter/construction.py` 解析显式模块列表、受支持的推导式、简单本地工厂和默认 deepcopy。循环必须具有固定次数和直接串行递推，保留每个具体实例与准确的前后依赖。当前上限为 16 个元素，整体抽取还有节点预算。

重复次数、同构性、模块对象身份、参数关系分别记录。共享对象的三次调用和三个独立对象的调用有不同契约。异构序列可以保留元素次序，但不自动选择一个同构代表。动态次数、提前退出、集合修改、别名写入、局部 helper 修改、未知调用逃逸等条件会阻止升级，继续显示模板及未解析边界。

这项能力已用向量残差栈、卷积栈、共享对象、异构列表和重命名反例验证。它不以某种网络家族为入口。

### 2. 带来源的局部语义契约

`semantic_adapter/contracts.py` 在抽取图上检查实际操作数，生成版本化记录，包括成员、关系、角色、来源、依赖契约、适用调用及未断言属性。`schema.py` 核对引用和事实图摘要；追加运行观测不会使未改变的源码事实失效，实际修改源码事实仍会使旧依据失效。

已支持的主要局部契约：

| 契约 | 判定依据 | 必须保留的边界 |
| --- | --- | --- |
| 残差及前/后归一化 | 同一结果槽进入主分支和准确加法操作数；归一化输入位置可追踪 | BatchNorm 与 LayerNorm 分别显示；不推断原地别名等价 |
| 前馈链 | 完整局部 Linear → activation → Linear 依赖链 | 未知或可变运算不能直接跨越 |
| 缩放点积注意力 | 乘法操作数、转置轴、Softmax 轴与缩放来源 | 候选路径不能自动升级为完整多头结构 |
| 多头局部结构 | 投影、分头/换轴、内部计算、合头及输出投影 | 头数来自实际轴和构造绑定；rank-4 shape 本身不充分 |
| 同源 / 异源输入角色 | 投影前的 producer 与输出槽 | 不根据参数名字猜测 Self/Cross；不自动断言因果 mask |

尚无 Encoder/Decoder 整体家族分类器。Dropout、分支、数值保护与异常边界仍保存在事实 IR 中，不能被当作恒等运算删除。

### 3. 观测索引与保守关联

`observations.py` 对记录中的层级、算子、来源、分支、模式、张量 producer/slot/dtype 建立结构归组。只有通过且未截断的记录参与分组；每次执行和调用的原身份均保留。结构分组不声明数值、shape、未记录标量参数或未观测行为相同。

源码模块与运行调用仅在对象路径和调用候选充分唯一时关联。真实 CPU 检查发现，共享模块的 hooks 可能只报告其首个注册路径；现在按共享对象身份扩展候选，保留歧义，避免把所有观测错附给第一层。

共享栈和独立栈分别执行了两个明确 eval 输入，隔离 CPU 与重放检查通过，覆盖状态仍为 `partial`。其他比较案例复用的旧 receipt 在分析报告中明确标注，不算新执行。

### 4. 语义粒度与局部版式

证据模式 `source/runtime/merged` 与展示粒度 `overview/modules/detailed` 是两个独立维度。粒度按语义前沿和可见预算选择，重复、控制模板和运行实例不随“细节”自动全部展开。

同构重复可以聚焦第一个具体实例，明确标记 `Instance 1 of N` 及共享关系；其他实例仍在原始 IR 中，详图准确记录输入输出切边。画幅不足时使用实际印刷字号审核紧凑布局或更粗的语义前沿，记录请求粒度、实际选择和留待模块详图的部分，不以缩小文字冒充详细表达。

当前布局原语包括主流程、分支等宽、证据支持的残差旁路、标题保护、折叠重复边界和依赖合绘。合绘线保留所有成员、消费者和操作数，在 SVG 中记录 `data-bundle-members` 与逐成员 `data-bundle-endpoints`，不把多个调用变成一个调用。

重复层对同一外部结果的多次使用也可合绘。这由 `serial-repeat` 边界触发，对共享上下文、控制参数或旁输入都适用；条件/状态边继续分别显示。尚未实现任意双流的完整排版语法，也没有为某个模型固定双栏、三列或 memory lane。

## 审核闭环与本轮自省

每轮保存同源码、同构造配置的旧抽取+旧绘图、新抽取+新绘图，以及旧 IR+新绘图。第三项用于区分语义变化与纯绘图变化。默认构造与小配置分别比较，不相互替代；专用图的节点数和像素尺寸不是通用图的目标值。

审核包含四部分：

1. 契约正反例：改名、轴变换、错误缩放、未知/可变算子、共享参数、条件和动态构造。
2. 原始节点/边去向：完整且唯一地记录可见、折叠、附属、收缩与证据模式排除项，确认输入 IR 未变。
3. 实际 SVG：独立读取 XML，检查父框绘制顺序、坐标变换、路径、真实端点、逐成员关系和标题基线，避免只检查路由器自己的数据。
4. 浏览器和目视：用真实字体测量节点/端口文字，分别审视总览、代表实例、细节和失败反例。文字不溢出不等于图面易读。

本轮审核实际发现并修正：父框后画覆盖子标题；已有同成员语义块重复套框；流程折行侵占残差旁路；折叠重复模块后外部依赖按每层复制。最后一项在默认比较图中曾产生 38 条可见连线和 152 个交叉，虽未违反路径与字号硬检查，仍明显妨碍阅读；通用重复边界合绘将其降至 13 条可见连线、1 个交叉，原始成员不删减。

仍有视觉代价：向量残差主流程变为纵向后更容易追踪旁路，但图高由 159.4 增至 240 mm、线长由 341 增至 787；卷积残差交叉消失，但最小字号由 9.37 降至 8.99 pt。广泛语料中的一个循环详图通过紧凑布局使字号从 7.97 提高到 8.17 pt，交叉由 4 增至 5。它们是明确取舍，不是所有指标单调改善。

## 后续优化顺序与验收

| 方向 | 继续学习的通用能力 | 验收要求 |
| --- | --- | --- |
| 构造语义 | 扩大可验证的工厂和集合绑定子集 | 独立/共享/异构、重构及副作用反例；不通过放宽未知边界提高覆盖 |
| 契约组合 | 从已证明局部接口组合更大结构 | 保留条件、槽位、资源、调用范围；未知操作阻断不成立的命名 |
| 跨运行收敛 | 将稳定架构对象与不同观测变体更清楚地组织 | 增加运行不会线性复制主画布；分支和模式差异不被拼接 |
| 布局语法 | 共同结果总线、双流通道、可组合的分叉/汇合约束 | 用多个无关领域图验证，端点身份优先于对齐；不得以模型名称选模板 |
| 阅读质量 | 主路径显著性、旁路长度、嵌套框冗余、版面密度 | 同配置截图、实际尺寸、局部详图与反例；记录任何退化 |
| 持续验收 | 固定回归集并扩展未参与调参的独立案例 | 每轮绑定来源、配置、实现、SVG 和视觉结论，不套用旧阶段通过记录 |

应优先解决跨折叠边界的共同值表达和冗余源码包装，其次推进更大的契约组合与双流排版。当前已经接近“规则支持的局部人工语义审核与版式选择”，尚不能宣称任意陌生程序自动获得专家级完整架构图。
