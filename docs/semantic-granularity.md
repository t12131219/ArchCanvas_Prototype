# 中间语义状态与底层细节

目标是在保留原始事实图的前提下，由通用规则生成可逆的语义展示。其中一个中间状态应在模块逻辑和视觉组织上尽量接近专用案例 01093cc06a87b35a；专用案例的全展开状态不是通用图的展开上限，也不是通用规则的模型专属模板。

这不要求先绘制全部细节再逐级收起。系统从原始 IR 提取局部关系，选择摘要、角色、计算路径或源码细节，再对当前可见对象重新布局。不同区域可以采用不同粒度。摘要应保留真实接口、操作数及结果绑定、共享身份、条件、状态和未知边界；更紧凑的图不自动代表更充分的细节覆盖。

预期阅读路径是：模型概览 → 架构语义状态 → 局部角色及计算细节 → 原始源码事实。它不是固定的四档全局深度，也不要求所有区域同步展开。语义关系可能交叠，必要时通过来源映射和源码视图继续检查，不能承诺所有原始对象都属于一棵语义容器树。

当前验证分别支持以下结论：

- 历史源码投影检查恢复 3371 个节点、3663 条边，全部 canonical ID 可见，原始 IR 未变。证据见 `verification/summary-coverage/current/source-expandability.json`。
- 局部摘要已有展开、收起和保存重开的验证；本次结构优先策略仍保留手动细化能力。
- 数千节点同时进行完整 SVG 布局、路由和浏览器交互的性能尚未验证。数据可恢复不等于整图同屏可流畅操作。
- 当前通用 Transformer 尚未达到专用参考的整体表达和版式目标。局部自适应策略也尚未构成全局表达及图组规划器。

优化应继续围绕来源分组、分叉汇合、局部旁路、上下文依赖、重复、状态和条件边界等通用关系进行；Transformer 用于对照验收，同时用陌生、残缺和混合案例检验规则的可组合性。
