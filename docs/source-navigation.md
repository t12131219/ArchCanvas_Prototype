# 从语义主图进入最细事实的定位

本轮补齐一项此前未验证的范围：实际完整源码路由及数千节点编辑器往返。输入仍是 `verification/helper-contracts/current/Transformer-current.json`，SHA-256 为 `b1848176e4dc66c7cf4add5656684e5cc686a97532e39fe3e0d51eafff2315cb`。它只是验收输入；新增能力适用于任意当前可见图。

## 实际问题与实现

完整展开确实恢复全部 3371 个节点、3663 条边，路由均成功；但原始画布是 3026 × 245352。缩到一屏后几乎成为细线，仅凭“节点可恢复”无法证明细节方便检查。

编辑器现在提供“查找当前图元”。它按名称、当前范围、模块路径或源码位置查找，只列出真实可见对象，多个搜索词需同时匹配。结果最多显示 40 项，并给出总数和缩小范围提示；没有匹配时说明可以展开相关区域或切换源码层级。输入 Enter 定位首项，Escape 清空；每次展开、折叠或切换表达后重建当前索引。

定位仅移动镜头并打开已有证据面板。闭合节点按原始比例居中；展开外框定位标题，避免再次把巨大子树缩成细线。结果说明去除重复来源，显示前两处及其余数量，查找仍覆盖完整来源位置；具体模块路径帮助区分同名角色和不同实例。文字通过 `textContent` 创建。生产代码没有模型名、案例 ID、源码哈希或参考坐标选择器。

该功能不跨隐藏节点自动展开，不修改语义折叠请求、IR、位置或路径，也不将未知调用标为已解析。它辅助从中间状态检查更细事实，不能替代主图与专用参考的语义及版式收敛。
