# 阶段概览中的源码读取路径摘要

本轮在通用阶段概览中加入有边界的属性读取路径摘要，继续服务 F0「接近专用完全折叠」目标；F1「接近专用展开」目标继续保留。选择规则不读取模型名、案例 ID、源码哈希或参考图坐标。整体视觉与语义收敛仍未完成。

## 摘要成立的条件

候选来自已提取的 source-function / source-module 局部范围，只允许明确的 `self.attribute` 静态读取发生、已建模算子和精确输入输出绑定。源码读取不等于不可变缓冲区，不证明别名身份、纯函数或外部副作用。未知调用、条件、写操作、状态输入、读取逃逸和其他受保护边界继续阻止相应候选。独立成立的相邻摘要仍可保留。

原先的 operand-expression 仅是展示分区；只有其原始成员、切边及端口与规范 IR 完全一致，才允许穿透它检查所属 helper。摘要保留原始成员、全部边界和来源，不删除 IR。

读取路径采用有编号的依赖图。例如：

```text
#1 getitem
#2 device-cast ← receiver=#1
#3 add ← 2=#2
#4 Dropout ← arg:0=#3
Reads self.table → #1[value]
Input x → #3[0]
```

编号描述结果引用，不宣称执行顺序。外部输入即使进入后续运算，也必须印出精确消费槽，否则不能自动收进摘要。精确切片、dtype 等配置仍保留在源码和绑定证明中，不能把摘要当作完整操作数已经直接展开。

同一对象的多次调用保持分开的卡片、输入及输出，打印 `Object 1 · source call 1/2` 等身份。读取名称相同不意味着结果相同。两次调用不会被合成一个张量值。

新形式只在可缩放画布的「阶段概览」启用；既有角色及打印档的契约保持原状。

- Transformer 最细源码投影保留全部 3371 节点、3663 边；这不等于数千节点完整 SVG 的布线与浏览器性能已经通过验收。
