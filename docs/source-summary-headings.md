# 阶段摘要保留源码调用名

继续同时追踪 F0（接近专用完全折叠图）与 F1（接近专用展开图），并保留更深的源码展开。本轮改善粗档中 helper 的可辨认性：已保留完整操作数绑定行的 DAG 摘要可以用 `Source: <源码调用名>` 作标题。原结果标题、每步操作、精确消费槽、来源读取和共享调用序号仍在摘要中显示。源码名只标识调用，不证明 Position Encoding、Attention、RNN 或其他模型语义。

## 通用规则与保留条件

规则只用于 stages 画布中当前折叠、已能以精确绑定行表达的局部 DAG。标题直接来自规范源码节点，不能来自模型分类、推测的功能名或专用参考图。每份绑定行继续使用原 schema、原引用和原内容，前沿及规范 IR 不变。

摘要检查器仅为这项明确表示开放标题搬移：要求规范节点 ID／源码名匹配、真实标题精确匹配、原结果标题与 `Dependency DAG` 连续打印，并且独立重建的全部操作数行、输入、读取、调用身份和边界路径仍满足。不能一般地用任意 caption 替代 title。伪造源码名、结果引用、节点身份、缺失结果文字或绑定行均导致检查失败。独立 Python 审核还从物理源码 AST 核对实际调用选择，并检查真实 SVG 文本。

最终选择先保留已有绑定行表示，再测量至多一个完整标题候选，避免长名称反向改变内部摘要选择。仅在前沿、accounting、原始绑定、已满足目标和已实现约束全部保持，同时宽高、线长、字号和冲突均不退化时采用。等尺寸可接受，因为收益是恢复源码标识，而非缩小面积。长名称不合格则原图逐字节保留。

`diagnostics.routing.source_summary_headings` 记录是否采用、保持条件和前后指标。`paperSourceHeadings:false` 禁用，显式 true 供实验使用。手动位置、非画布、非 stages、超过 128 条可见边及没有完整绑定行的图不启动此项自动比较。现阶段不改变 path/tree 摘要标题。增加的是一个有界完整候选流程；没有测得总体性能改善，不能据此宣称更快。

## 实验取舍与泛化

曾在临时冻结副本尝试统一重命名 path/tree/DAG。Transformer 粗档从 848×1676 增至 848×1692、线长从 15059.3 增至 15187.3，因此未推广。该临时试算不是正式审核产物。

新增物理源码 `tests/semantic_fixtures/source_summary_headings.py` 的 8 个入口不执行源码，覆盖普通计算、长名称、未知邻居、条件、状态、共享调用、可变邻居和内部未知行为：

- 普通、未知／状态／条件／可变邻居：保留已证明 helper 的源码标题，边界和所有连接不变。
- 共享调用：两个摘要保留独立节点、读取引用和调用序号。
- 长名称：最终候选增高，自动拒绝；SVG 与基线相同。
- 内部未知：不形成这类 DAG 摘要，未知节点继续显式存在。

8 项新增测试包含伪造／遗漏反例、误导性的熟悉名称、几何拒绝、保存重开、继续展开、完整源码和选项保护。所有 1015 项测试／92 组通过。28 张正式 SVG 通过独立 AST／XML、规范绑定、目标、accounting、最终坐标和线路审核。浏览器核对 510 个图元、896 段节点文字，无文本越界。
