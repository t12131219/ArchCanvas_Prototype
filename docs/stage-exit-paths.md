# 阶段概览：沿实际区域出口组织后续节点

本轮继续双目标：F0 阶段概览接近专用完全折叠图，F1 的选定语义状态接近专用展开图；两者之下都保留继续展开。专用 Transformer 只作评估，不参与生产规则选择。

## 通用变化

展开的源码区域可能有一个真实输出，其下游计算和 return 却仍靠在父框左边。现有 `regionFollowers` 原语可根据可见依赖提出水平对齐；本轮把这项能力用于 stages，同时增加完整渲染后的验收。没有新增 Transformer 识别器，也没有引用模型名、案例 ID、参考图坐标或 Encoder/Decoder 排列模板。

候选来自真实输入边：只允许一个来源区域、普通无条件数据关系和已存在的下游节点。保留节点归属、层次和依赖；多个来源、条件/状态路由、可变操作、共享调用身份、环、其他节点主体和已占用通道会限制提案。未知函数可作为明确的 opaque 输出节点对齐；移动它不意味着证明内部计算或将它当作透明连接。

局部对齐以后还会经过折叠选择、文字排布、空带压缩、端口安排和路由。因此局部收益不能直接决定最终结果：默认 stages 先完成普通图，再对至多一个完整候选进行比较。仅在以下条件同时满足时采用：

- 同一语义前沿、规范输入输出槽、节点/边去向、直接目标和摘要目标不变；已满足目标和已执行关系不能丢失。
- 最终线长至少减少 1px，宽度和高度均不增加，字号不减小。
- 不增加交叉、无关接触、歧义重叠、路由失败、未安放标签或质量问题。

不合格则保留原图。`diagnostics.routing.stage_exit_refinement` 记录提案、局部是否采用、最终是否采用、保留条件及前后实际指标。`paperRegionFollowers:false` 禁用；显式 true 供局部实验使用。手动位置、非画布、非 stages 和超过 128 条可见边的图不启动这项最终比较。新增成本最多是一次完整候选渲染，不能据当前并发采集耗时宣称性能改善。

## 泛化与反例

新物理源码 `tests/semantic_fixtures/stage_exit_paths.py` 静态抽取 7 个入口，未执行源码：

| 入口 | 实际结果 |
|---|---|
| OutletWorkshop | 不同深度的分支区域及跨区依赖；后续 Linear/return 对齐，652×1132 → 652×1124，线长 2594.3 → 2517.3，交叉 0 |
| UnknownOutlet | 未知 foreign_finish 仍明确可见，其输出链获得相同的对齐收益 |

## 两档评估

同一源码、同一状态与冻结基线 `bb45fd8` 比较：

| 状态 | 基线 | 当前 |
|---|---|---|
| Transformer F0 图元 / 连接 | 28 / 37 | 28 / 37 |
| F0 尺寸 | 848×1700 | 848×1676 |
| F0 线长 | 15578.3 | 15059.3（减少约 3.3%） |
| F0 交叉 | 9 | 9 |
| F1 三张既有状态 | 固定状态 | SVG 逐字节相同 |

F0 的 generator 与 return 现在沿真正出口排列；规范 IR、核心阶段和精确连接均不变。独立 Python 审核读取源文件 AST、SVG 文字与路径、规范绑定、节点/边去向、直接与摘要目标、最终节点坐标及约束结果。26 张正式 SVG 通过；1007 项测试 / 91 组通过。浏览器逐项核对 778 个图元、1387 段节点文字，无文本越界。

真实 UI 小例验证阶段概览 20 图元 → 展开内部区域 30 图元 → 保存重开 → 全部源码 54 图元 / 52 边 → 返回概览。导出与正式 SVG 对应。Transformer 的原始源码投影仍完整保留 3371 节点 / 3663 边；该检查不包含数千节点全量 SVG 的路由和浏览器性能。

同一编辑器导入固定 Transformer F0 → F1 → F0 图文档，观察到 28 / 65 / 28 图元；三次实际 SVG 导出分别与正式产物逐字节一致。这是固定文档导入往返证据，不扩写为下拉控件的前沿切换验收。

此前在临时目录试算过输入重排：直接推广输入 docking、强制上下文通道及其组合均增加交叉；选择性移动单个输入也未通过几何比较。因此没有启用这些方案。临时试算不是本轮正式产物，不能据它们宣称通用入口排布已经改善。

## 剩余差距

F0 仍偏高，外部输入和跨区上下文连线复杂，阅读方向和元数据密度与专用图不同。F1 整体收敛、最终双档控件往返以及数千节点 SVG 性能仍待完善。当前改动是一项可组合布局能力，不能代表折叠与展开双目标已经完成。
