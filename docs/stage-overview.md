# 阶段概览：双前沿目标的增量

2026-10-22。本轮基线为 `441c3ab`。新增可缩放画布的 `stages`（阶段概览）预设，作为 F0 候选；F0/F1 与专用图的整体语义及视觉收敛仍未完成。原有语义边界、角色关系及其他预设不改名、不替换。

## 通用规则

阶段摘要和角色展开独立选择。阶段概览复用已认证的后置归一化阶段与精确 helper 依赖摘要，但停在已认证复合模块边界，不启用角色前沿的内部展开。串联、残差、重复实例、条件、状态及未知边界仍由原有事实和接口决定。

生产代码没有模型名、类名、案例 ID、源码哈希或参考坐标选择器。新用例从实际 Python 源码抽取，覆盖串联旁路、逃逸输出、未知调用、单步状态、条件和重复组合。中间结果逃逸或条件使局部摘要不成立时，只拒绝该范围；独立已知部分仍可摘要。框架单步状态调用保持可见，不混入普通 helper 摘要。改名不改变摘要选择。

摘要可双击继续展开，也能回到阶段概览。保存文档只改变可见前沿，原始节点、边、证据、来源及参数读取均保留。内部计算被摘要后不计为直接展开目标。当前阶段摘要特性仅在可缩放画布生效；选择单页打印不会获得这一组新增摘要，尚未对打印建立相同 F0 保证。

当前粗档保留三个注意力、两个前馈、五个 Add & Norm、重复层代表和后续调用、残差及外部上下文连接。两个 embedding helper 成为依赖路径摘要。直接目标减少是显式折叠的结果，不应解释成细节覆盖增加。字号为原始 13 px，浏览器全图缩放后的字号另计。

视觉审核确认还不接近最终专用折叠版式：位置编码细节较多，原始调用与重复余项占空间，主链自顶向下，memory 连接尚未形成专用图那样清楚的总线。下一步应从通用的局部算术/缓冲区路径摘要、重复范围表达、跨区上下文通道和依赖驱动并列布局改进，不能针对 Transformer 固定两栏或删除其独有细节。

专用参考来自既有真实编辑器 SVG：折叠 23/25，展开 83/85 个节点/边；数量只标识参考版本。通用 F1 的三个已选细节状态在本轮前后文档和 SVG 完全一致，不宣称本轮改善 F1。截图中的末端 Softmax 位于被分析 forward 之外，保留为参考说明，不补成源码执行事实。

## 验证及复现

完整回归为 964 项、87 组。正式 38 张 SVG 包含六个陌生组合的新旧预设对照、各自的局部展开、三个旧预设回归及 Transformer F0/F1 对照。独立检查器读取实际 SVG 文字、坐标、路径和端口元数据，重算交叉、接触与重叠，并对照规范 IR 检查 stage/helper 成员、切边和绑定；允许穿过展开模块标题，实际节点及无关主体仍检查避让。原始直接目标与质量合格目标分别记录。浏览器另验实际字体和标签边界，并核对路径、文本及分叉点与磁盘 SVG 一致。

真实 UI 用例验证阶段摘要局部展开、保存重开、源码全部展开及恢复粗档。Transformer 全源码投影保留 3371 节点/3663 边；不把投影完整性当作数千节点完整 SVG 路由或浏览器性能通过。本轮尝试从全部源码状态切回论文视图时触发了耗时布局，未将该交互列为性能验收通过；随后通过固定粗档文档重新导入验证。
