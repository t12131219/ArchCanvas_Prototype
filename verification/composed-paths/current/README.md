## 目视自省

自动摘要减少了纯源码包装带来的纵向层级，拆成 helper 不再使同一条路径变成
不同的架构解释。继续展开仍可看到来源框和具体操作；没有虚构运行顺序或融合。
这只是受限串联路径的源码重构稳定性，不覆盖任意跨 helper DAG 或分叉摘要。

未知、条件、外流和共享案例保持原有几何；ConditionalComposition 仍有 2 处交叉。
细节图高度增至 968 px，属于恢复全部操作和来源层级的成本。源码切边证明增加
文档大小；并未删除底层来源框或认证边界。

与专用参考图的对照仍显示大范围包装、长线及稀疏区域。Transformer 本轮没有
新的组合路径，尺寸与交叉未改善；目标仍未完成。下一步需要在保留这些组合
不变量的基础上，处理更一般的区域表达、跨区域连接和整图粒度选择。
