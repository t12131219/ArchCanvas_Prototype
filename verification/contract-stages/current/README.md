# 本轮审核：认证角色子区域

通用画布的“角色关系”状态可将现有残差证书中的相加与后置归一化形成
`Add & Norm` 阶段，向下仍能展开原始操作。规则不读取模型名、案例 ID 或
源码 SHA。Transformer 与向量、卷积、串联、条件、未知和外流组合共同评估。

- 343 项测试通过，包含 9 项本阶段新增测试。
- 64 张 SVG 通过独立 XML、绑定、accounting 和几何检查。
- 实际浏览器文字边界检查：64 张，0 处溢出。
- 实际 UI 节点数：11 → 13 → 13 → 11 → 15，对应折叠、单个阶段展开、
  文件重开、再折叠、全部展开；SVG 与 CLI 一致，原始绑定及 IR 保留。
- Transformer 中间视图：105 → 100 节点，111 → 106 条边；
  2588 × 4730 → 2588 × 4502 px；交叉保持 57。30 个候选阶段中，
  当前代表层前沿显示 5 个，5 条已实现旁路约束保留。

审核中发现并修复了两点：全部展开需要合并源码和展示索引；被折叠的前置
阶段输出仍须作为后继 skip 的精确来源。阶段只引用最终约束审核记录，避免
复制布局阶段的初步成功状态。

## 自省与后续重点

单独展开 Transformer 的一个新阶段后，整图为 102 节点、107 边，
2332 × 5456 px、81 处交叉。增加的外框影响了全局布局和路由；下一步需要
改善局部展开的几何稳定性。

条件组合中，独立阶段的形成改变了自动前沿选择：true/false 区域保持折叠，
其内部原始计算和一条旁路约束暂缓。控制边界保留，但自动预算仍依赖当前
容器组合，需要减少无关区域的粒度波动。

TailMosaic、InterruptedTail 各保留一条历史已存在的最终通道冲突；本轮
没有新增冲突，也没有把这些约束宣称为完成。直接、单用途的同级操作是
当前适用范围，别名或间接连接的尾部仍保留既有表达。

与专用参考图的完整模块、角色及视觉对应仍未验证。当前改变改善了中间
语义状态，细节布局与整体架构组织仍需要继续优化。
