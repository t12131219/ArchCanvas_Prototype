# 本轮审核：维度配置证明与局部路径折叠

通用规则重新推导 Tensor 维度来源，逐步核对别名、结果槽、整数运算与配置使用。
配置专用的路径附在消费节点上，真实计算保留在规范 IR 和证明记录中；特征使用、
返回值、共享读取、未知及条件边界继续显式展示。不使用 Transformer 专用匹配。

357 项测试通过。87 张正式 SVG 通过独立源码 AST、XML、原始操作数、结果槽、
切边、accounting 和几何审核。实际浏览器检查 3214 处文字，0 处边界失败。
7 个新样例以静态抽取复现，未执行运行追踪。真实 UI 的折叠、展开、重开、
再折叠为 9 → 12 → 12 → 9；SVG 与 CLI 一致，原始 IR 和绑定不变。

Transformer 新增三个“transpose → copy → reshape”路径说明，总计 12 个可见局部
路径说明。自动语义状态没有减少节点和交叉；说明文字使高度增加 28 px。不能据此
声称整图更加紧凑。同一 helper 展开状态减少的两个节点及六条边是维度配置附注，
不是删除操作；270 条维度证明行保留其来源、依赖及使用。

## 目视检查与自省

`DimensionWeave-dimension-comparison.html` 对照冻结、摘要与继续展开。
`AliasExtent-dimension-comparison.html` 检查多级配置证明；其余五组对照检查
特征乘积、返回维度、未知计算、条件 phi 与返回 shape 的显式边界。共享或外流
运算没有被配置折叠吞没。ContextWeave 和 BoundaryWeave 的中途上下文来源与
消费端细节也保留，避免自动摘要造成跨区域连接退化。

`dimension-helper-comparison.html` 仅修改实际 SVG 的 viewBox，检查局部变换仍可
展开。裁剪外连线不表示新增接口。`dimension-expansion-comparison.html` 检查整图；
`transformer-comparison.html` 与专用展开参考对照。通用图仍有较多源码包装、长上下文
线及稀疏区域；默认图仍有 57 处交叉，尚未建立参考图的角色/边界对应。

本轮所有 before/roles 对照没有新增最终约束冲突；历史旁路冲突仍如实保留。
维度值不求解、不验证形状、执行或纯度。未知副作用后的全局符号读取屏障仍沿用
原策略，不能宣称所有独立后续读取均已恢复。配置证明行增加文档体积和审核成本。
