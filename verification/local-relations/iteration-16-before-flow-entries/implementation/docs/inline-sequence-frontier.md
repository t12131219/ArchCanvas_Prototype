# 整图中的具体结构代表与语义边界

本轮继续推进通用层的中间语义前沿。参考 Transformer 专用图仅用于评价；生产规则不读取模型名称、案例 ID、源码摘要或模型家族。目标仍未完成，不能把当前前沿称为参考图的对应前沿。

## 已实现的通用规则

`semantic_studio/sequence-frontier.js` 在当前事实图上重新检查结构证书。每个已证明结构组的首个具体调用可以在原序列位置展开；同组、连续、非代表的两个以上后续调用可以折叠为一个摘要。异构位置不跨越合并；未知和可变计算不加入已证明摘要。原调用、对象身份、条件、操作数和精确切边仍保留，摘要可以继续展开。

代表只解释局部结构。它不代替后续调用的值，不表示结果相等、参数稳定、计算纯净或运行次数已经得到验证。每个展开序列获得独立的局部前沿预算，父区域将它计为一个展示单元。

“展示粒度 → 语义边界”沿普通来源包装和展示区域继续展开，到已有语义证书支持的模块边界停止。因此同类已认证模块不会仅因广度优先遍历顺序，一处展开到算子，另一处仍封闭。手工展开仍可进入内部。其他预设以及单页打印的既有输出继续由各自规则控制；可缩放画布可以选择“重复结构 → 序列摘要”恢复先前的序列表达。

`architecture-layout.js` 新增可选的端口对齐。只有目标复合区域具有独立来源的入口，而且跨区域依赖确实进入其内部后段，才尝试让两个外框在纵向范围上部分重叠、横向分列。普通串联和控制依赖保留完整外框间距。候选需要减少高度与最长阅读跨度，并限制面积增幅；布局记录接受或拒绝及候选尺寸。它描述阅读位置，不推断执行并行或调度。

源码抽取还修正了连续两个认证循环复用同一个迭代变量的情况：进入具体迭代前，Python `for` 目标覆盖之前的变量绑定。该修复没有放宽其他未知重绑定调用的规则。

## 验证与范围

运行：

```sh
python3 tools/run_local_tests.py
node tools/audit_inline_sequences.cjs
python3 tools/audit_local_svg.py --inline
python3 tools/build_inline_review.py
```

证据保存在 `verification/inline-sequences/current/`。17 个图面覆盖同构、异构、未知、可变序列、后续调用展开、两个序列共享上下文、陌生组合和 Transformer 对照。它们属于开发与回归输入，没有将其宣称为未见验收集。浏览器还检查实际 SVG 文字边界，并通过真实文件选择器和导出对话框验证普通组合案例的保存、重开、继续展开与折回。

本轮冻结点为 `verification/local-relations/iteration-10-before-inline-sequences/`，不得修改。旧报告属于旧实现；当前阶段的生产、测试、SVG、浏览器与 UI 摘要应分别核对哈希。

## 仍未解决

- 尚未建立通用前沿与参考展开图的节点、角色和边界对应关系；当前语义边界仍将认证模块封闭，参考图则表达更多内部角色。
- 来源包装和实例包装仍占用较多空间，跨框上下文线路也较长。当前 Transformer 语义边界图为 66 个图元、60 条连接、1756 × 5008 px，仍有 22 处交叉。
- 更深预设保留 112 个图元、105 条连接，但触发画布面积预算。不能用通过路由检查来宣称视觉收敛。
- Python 既有摘要依赖 JSON 数字拼写；JS 保存会将例如 `1.0` 写成 `1`。原始 Transformer IR 可通过 Python 验证，保存文档的 JSON 数值与原始事实一致，但旧摘要可能无法直接通过 Python 重算验证。本轮独立审计验证原始输入证书，再比较导出事实，未重新签发或宣称旧摘要通过。跨语言摘要契约仍需单独修复。
