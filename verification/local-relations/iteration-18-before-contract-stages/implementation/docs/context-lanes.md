# Measured context side entries

The canvas roles frontier can propose side entries using only visible dependency topology. An ordinary unconditional value enters a visible container from outside, reaches a consumer that also has an independently connected internal input, and has no reserved bypass/state/iteration route. Ancestor interfaces and folded containers keep their original boundary behavior. Bundles qualify only when every member does. A context entry is a drawing preference, not proof that the value is auxiliary, pure, shared, equivalent, or scheduled differently.

The proposal allocates a separate gutter next to existing semantic lanes and gives each consumer operand a distinct physical side terminal. The original edge, tuple slot, conditions, evidence and bundle members remain unchanged. A route can fall back around obstacles. Exported `context_lanes` receipts distinguish an actually realized vertical channel from a deferred channel; a side terminal alone is insufficient to claim realization.

Automatic canvas roles layout tries one bounded left-side alternative when crossings remain and qualifying inputs exist. It adopts the candidate only if the visible nodes and exact presented edges stay the same, crossings strictly decrease, no new quality issue appears, contacts/route failures/missing labels do not increase, native text remains readable, area grows by at most 15%, and wire length grows by at most 10%. Manual offsets, manual frontiers, print views and explicit settings are preserved. Right-side routing remains available to the evaluation harness as an explicit experiment; it is not an automatic second search.

Lower crossing counts do not by themselves establish readability or reference correspondence.

## Observed result and limits

The same-source evaluation keeps 105 visible objects and 111 presented dependencies. Actual SVG crossings fall from 84 to 65, width grows from 2332 to 2588 pixels, height stays 5568 pixels, and total wire length grows from 83457.7 to 87508.6. Only 3 of 12 proposed channels realize a vertical lane; 9 are explicitly deferred. A forced right-side experiment produces 89 crossings and is retained only as evaluation evidence. An unrelated mixed candidate grows from 7 to 8 crossings and is rejected; all ten other paired evaluation SVGs remain byte-identical.

309 tests, 28 independently audited SVGs and 28 browser text-bound checks pass. Actual mixed editing retains 29 → 33 deeper expansion → save/reopen → 29 refold. One operand label still needs a note in that deeper manual state. Static browser SVG review confirms a less crowded consumer entry but still staggered branches, long context wires and a much taller composition than the dedicated reference. Transformer editor role switching timed out in the browser automation; this stage does not claim an interactive Transformer editor verification. The extra bounded render also needs future responsiveness work.
