# 本轮审核：语义粒度与手动展开的布局稳定性

本轮修正两处通用耦合，不增加 Transformer 专用规则：

1. 先在原有证据图上选择自动展开层级，再形成认证语义阶段，避免改变无关区域的预算。
2. 将手动选择展开层级与手动移动位置区分开。画布手动展开仍运行有质量门槛的布局候选；实际位置偏移和显式设置继续保留。

345 项测试通过。70 张 SVG 通过独立 XML、原始绑定、操作数、结果槽、
accounting 和几何检查；实际浏览器文字边界检查 0 处失败。真实 UI 的折叠、
展开、重开、再折叠和全部展开节点数为 11 → 13 → 13 → 11 → 15；
SVG 与 CLI 一致，原始 IR、认证归属及切边绑定保留。

| 比较对象 | 冻结基线 | 本轮结果 |
|---|---|---|
| Transformer，同一手动展开列表 | 102 节点 / 107 边；2332 × 5456 px；81 处交叉 | 102 / 107；2588 × 4502 px；57 处交叉 |
| Transformer，语义折叠状态 | 100 / 106；2588 × 4502 px；57 处交叉 | 相同 |
| ContextWeave，手动粒度 | 540 × 792 px；0 处交叉 | 540 × 700 px；0 处交叉 |
| BoundaryWeave，手动粒度 | 553 × 808 px；0 处交叉 | 553 × 716 px；0 处交叉 |
| ForeignComposition，自动粒度 | 34 / 35；836 × 2610 px；6 处交叉 | 28 / 30；652 × 2216 px；3 处交叉 |
| ConditionalTail，自动粒度 | 12 / 13；620 × 812 px；2 处交叉 | 16 / 15；671 × 1176 px；4 处交叉 |

条件案例的增加是恢复此前被预算干扰隐藏的分支内部计算。与禁用语义阶段的
同案例相比，自动展开列表完全相同，已实现旁路保留。这是恢复证据粒度的
代价，不能描述为几何改善。不同组合及预算均有回归测试。

## 目视自省

`expansion-comparison.html` 对照完全相同的展开列表；本轮恢复了分支列、
上下文通道和独立入口对齐。局部阶段展开后仍能检查相加及 LayerNorm，
未靠隐藏操作减少交叉。`ConditionalTail-stage-comparison.html` 展示了恢复的
条件内部计算，`TailMosaic-stage-comparison.html` 检查混合分支与可逆展开。

宽度在 Transformer 手动展开对照中增加约 11%，高度降低约 17.5%，
交叉减少约 29.6%。仍有 57 处交叉和长上下文连线；局部展开仍可能移动整图，
新增候选测量也增加渲染计算。TailMosaic、InterruptedTail 各保留一条历史
旁路通道冲突，没有新增最终约束冲突。

`transformer-comparison.html` 保留与专用展开参考的真实 SVG 对照。通用图仍有
较多源码包装层、稀疏区域和长线，尚未达到参考图的完整模块逻辑及视觉组织。
下一阶段应继续根据局部证据改善包装摘要、跨区域依赖组织和展开稳定性，并
在陌生及破碎组合中验证；不能以模型名套用参考图版式。

冻结基线为 `iteration-19-before-stage-stability`。此前审核产物未重新生成或
盖章。复现步骤见 `docs/stage-stability.md`。`validation.json` 记录证据一致，
汇总工具返回 2，明确总体目标尚未完成。
